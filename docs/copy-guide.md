# 文案规则

WindowShade 的界面文字照 macOS 自带 App 和“系统设置”的中文写法。拿不准时，在 [`apple-zh-strings.tsv.gz`](apple-zh-strings.tsv.gz) 里找同类的说法照着写，不另起说法。这份文件是 macOS 26 “系统设置”各页和访达的简体中文界面文字，由 CI 的 Test runners 任务取出（`.github/scripts/apple-zh-strings.py`），例如 `gzip -dc docs/apple-zh-strings.tsv.gz | grep -a 若要`。

## 规则

每一条都能拿一句具体的文字对着判断对不对。

1. **设置里一行只有名字和控件。** 不在下面加一行小字解释。名字说不清这一项做什么时，改名字，例如把“看一眼”这一行叫作“指针悬停在卷帘条上时显示窗口”。只有两种小字可以出现：随系统设置变化的状态，例如“三击标题栏会缩放窗口”；出了问题时告诉用户怎么办，例如“请在‘系统设置’的‘登录项’中允许”。
2. **不写不会发生的事。** 不写“不自动安装”“不上传”这类话。
3. **按钮写动作，动词开头。** 打开系统设置、检查更新、恢复默认。
4. **说操作方法时用系统的句式。** “若要……，请……”，例如“若要更改快捷键，请连按组合键，然后键入新键。”（系统设置原文）
5. **快捷键显示成系统的样子。** 和菜单里一样显示 ⌃⌘C；写在句子里时用键名，例如“Control-Command-C”。
6. **菜单栏上的提示说原因，不超过 14 个字。** 例如“全屏时不能收起”“窗口太矮，不能收起”。不写“这个窗口不能收起”这种不说原因的话。
7. **不写宣传语、版权、作者名。** “关于”窗口只有名字、一句用途、版本号和 GitHub 链接。
8. **一个东西只有一个名字。** 用下表的词；表里没有的新概念，先加进表里再用。

## 用词

| 概念 | 用词 | 不用 |
| --- | --- | --- |
| 把窗口收成一条的动作 | 收起窗口 / 展开窗口 | 折叠、卷起、卷成 |
| 收起后留在原处的那一条 | 卷帘条 | 标题条、strip |
| 收起后卷帘条的样子（设置项“收起后显示”） | 原标题栏 / 简化标题栏 / 缩略图 | 原貌卷帘、统一标题栏 |
| 把卷帘条排到屏幕一侧、再放回 | 整理卷帘条 / 把卷帘条放回原位；缩略图同样叫整理缩略图 / 把缩略图放回原位 | 排列、归位 |
| 指针悬停在卷帘条上时显示窗口 | 看一眼 | 偷看、预览、peek |
| 卷帘条在其他窗口前面 | 卷帘条置顶 | 浮动、钉住 |
| 修饰键加 1 至 9（默认 ⌃⌘）展开第几个收起的窗口 | 按编号展开 | — |
| 首次打开时的授权窗口 | 欢迎使用 WindowShade | 新手引导、教程 |
| 两项系统授权 | 辅助功能、屏幕录制（macOS 26 上和系统一样叫“录屏与系统录音”）；按钮“打开系统设置”，授权后显示“已允许” | 去授权、权限缺失 |
| 系统的空格键预览 | 快速查看 | Quick Look |
| 更新 | 检查更新、自动检查更新 | 升级、版本检测 |
