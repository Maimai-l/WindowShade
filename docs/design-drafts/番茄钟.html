从 Tomato Ritual 取什么

它把“休息”做成仪式：多屏毛玻璃、呼吸光环、按 Esc 随时退出。我们取这份仪式感，但不另造幕布。

它的做法WindowShade
多屏毛玻璃幕布 + 呼吸光环，Esc 退出全部收进刘海：桌面一下子空了，刘海里一圈呼吸的光；任意键或点一下，窗口原样回来
按截止时间计时，睡眠合盖不漂照做
锁屏、离开自动暂停专注暂停；休息照走
菜单栏、迷你 HUD、桌面小组件刘海一处全包了
三个全局快捷键一个：开始 / 暂停（默认空着）
白噪音、热力图、导出、任务名、长休息不做

全 App：一个符号能说清，就不写一句话

现在设置里 71 条副标题，39 条超过 20 个字，19 条超过 30 个字；整个 App 只有 27 处用了 SF Symbols。改成：每行前面一个符号色块，名字说事，副标题最多一行，细节进 ⓘ。

写给接手的人

  1. 番茄钟不开窗口。只用刘海、实时活动、收进刘海、全部收进刘海。
  2. 按截止时刻计时。不累加 tick；紧凑态一分钟醒一次，进度环交给 Core Animation。
  3. 设置只有两项。要加第三项，先说服 Aaron。
  4. 休息不锁人。任意键、点一下、Esc 都让窗口回来，休息照走。
  5. 符号优先。新界面每行一个 SF Symbol，副标题一行以内；不用 faceid 指刷脸解锁。
