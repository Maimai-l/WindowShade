手边的每一样

WindowShade 2 · 设计稿 · 2026-10-03 · 鼠标、触控板、遥控器与手柄

手边的每一样，都更顺手一点

把 Mos 的平滑滚动、Mac Mouse Fix 的“按住拖动”、Remote Buddy 的沙发遥控，按 WindowShade 自己的那一套动作重做一遍。滚轮鼠标像触控板一样顺滑；妙控鼠标和妙控板多出中键和几个不撞车的手势；Siri 遥控器和 PS5 手柄既能在沙发上操作这台 Mac，也能指挥 Codex 和 Claude。像 iPadOS 一样：一个入口，一套动作，任何输入都能用。全部默认关，开了才接管。

自成一体：一个入口，一套动作，任何输入

博采众长不是把七个工具的功能堆在一起。所有设备最后都落到同一套动作上；没有指针的设备，用和 tvOS、iPadOS 键盘导航一样的焦点在刘海那一排、启动台、窗口浏览里移动。

一个入口

刘海：看不见的窗口、实时活动、指挥模式、遥控时的焦点都在这里。

一套动作

收起、收进刘海、看一眼、侧拉、分屏、画中画、启动台、换桌面、指挥模式。设备不同，动作相同。

指着用，或挪焦点用

触控板、鼠标、手柄触控板指着用；方向键、遥控器的环、手柄十字键、iPhone 遥控器挪焦点用。

不做配置工具

默认值好到不用改；能改的只有开 / 关和少数几档。不做宏、脚本、Webhook。

点一下这块，用键盘方向键、遥控器的环或手柄十字键（这里用按钮代替）挪焦点

一格一格，和顺滑地滑

普通滚轮一格跳一大段，眼睛要重新找位置。平滑滚动把每一格变成一段带惯性的滑动，方向一变立即跟上。在下面两栏里滚一滚，或者点“滚三格”。

五条原则

默认不接管

WindowShade 现在对输入只旁听。平滑滚动、改写按键要拦截事件，全部默认关；开了才装钩子，被系统停掉就退回原样。

按设备认

滚轮鼠标、妙控鼠标、妙控板、Siri 遥控器各一组设置；按稳定 ID 认，不按名字。

一套动作

所有设备最后都落到已有的动作上：收起窗口、收进刘海、看一眼、启动台、调度中心、指挥模式。

让位

Mos、Mac Mouse Fix、BetterTouchTool、Logi Options+ 在跑时，对应功能让给它们，设置里写明谁接管。

许可干净

Mos（CC BY-NC）、Mac Mouse Fix（自定义许可）、GPL 项目只借思路；MIT 项目的代码带版权声明再用。

写给接手的人

完整规格在 docs/input-devices.md，给 DeepSeek 的提示词在 docs/handoff/deepseek-input.md。

  1. 默认关，开了才拦截。主动钩子只在对应功能开着、对应设备连着时装上；回调 O(1)；被系统因超时停掉时退回不改写，并在设置里说一句。
  2. 点一下照常。中键、两指按下、轻点，都要先分清“点”和“拖”；判不准就按原样放行，不吞用户的点击。
  3. 不撞系统手势。妙控鼠标两指轻点两下、两指左右扫，妙控板三指拖移、四指扫，一个都不占；占了就是缺陷。
  4. 不拷 Mos、Mac Mouse Fix、GPL 项目的代码。算法独立写；MIT 代码带版权声明。
  5. 落到已有动作。不新造“打开脚本、运行 Shell”这类通用动作库。
  6. 能耗与延迟写进验收。回调耗时、空闲唤醒都要实测；平滑滚动滑完就停。
  7. 每一行都登记隐私。拦截滚轮、读表面触点、遥控器麦克风，都进隐私一栏。
  8. 游戏在前台时，手柄整个让开。不读、不改、不震；PS 键永远不占。
  9. 真机说了算。妙控鼠标、滚轮鼠标、Siri 遥控器、手柄没上手试过的，照写“没在真机上验证”。
