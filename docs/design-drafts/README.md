# 设计稿

三份可交互画面稿。单文件 HTML，用浏览器直接打开。

书面令牌仍以 [design-system.md](../design-system.md) 为准。两边不一致时，画面先照这里的稿做，不顺便改设计系统；差异记进 [design-grammar.md](../design-grammar.md) 的对照账，不在这里改数字。

改界面、官网或 README 之前，先打开对应的稿。稿是画面，不是源码，不嵌进工程。稿里画到刘海、侧拉、分屏、画中画的部分已不在产品里，不照着做。
