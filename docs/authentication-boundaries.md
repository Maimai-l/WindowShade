# 尊重使用者的认证与离位检测

2026-09-30。承接 [锁屏方案](lock-unlock-plan.md) 与 [行为学习研究](behavior-risk-research.md)。
用户新增声纹、嘴形、微表情、心率、熟悉位置、衣着与身体特征；要求安全、迅速、不误锁本人。
本文是产品取舍与接线验收条件；相机探针、离位策略为独立小样，尚未进入 App。

## 文献与选择

| [Barrett 等，2019，Emotional Expressions Reconsidered](https://eprints.gla.ac.uk/178385/) | 面部动作与情绪并非一一对应，存在情境、文化和个人差异 | 检测明确动作，不推断情绪、紧张、诚实或受胁迫；不要求“保持微笑” |

| [ASVspoof 2021 结果，IEEE/ACM TASLP 2023](https://arxiv.org/abs/2210.02437) | 54 支队伍；重放检测跨模拟/真实声学环境、合成语音跨数据集仍有泛化缺口 | 声纹不能只靠音高、响度、语速、停顿；声音相似、说对口令与防伪是不同判断 |

| [Chung & Zisserman，SyncNet，2016](https://robots.ox.ac.uk/~vgg/software/lipsync/) | 音画同步和正在说话的人检测 | 可研究当次挑战的音画一致性；同步本身不是活体证明，整段重放也同步；权重用途须独立核对 |
| [Pereira 等，ECG 数据采集系统综述，2023](https://pmc.ncbi.nlm.nih.gov/articles/PMC9921530/) | ECG 的采集硬件、姿态、时间与生理条件影响识别 | ECG 波形不是每分钟心跳数；不给心率贴“身份密钥”标签，不读取健康史 |
| [Cheung & Vhaduri，BioRob 2020](https://arxiv.org/abs/2008.10779) | 心率、步态、呼吸的情境依赖组合，leave-one-out 平均准确率约 0.93 | 不是单一心率的支付级证据；不因此让 Watch 常驻采集健康数据 |
| [Khan 等，SOUPS 2015](https://www.usenix.org/conference/soups2015/proceedings/presentation/khan) | 37 人实验与实地研究；91% 觉得方便，35% 因错误拒绝感到烦扰 | 验收看误提示/小时、恢复时间和用户放弃率；不以“无感”掩盖持续观察 |
| [Balagani 等，JCS 2018](https://www.nyit-lamp.com/gasti/publication/balagani-2018-impact/) | 62 人击键时序可推断应用情境，论文报告 95.15% | 不读文字也不等于匿名；只保留最少统计，不保存原始按键时序或应用名单 |
| [NIST FRVT 人群差异报告，2019](https://www.nist.gov/publications/face-recognition-vendor-test-part-3-demographic-effects) | 匹配错误有算法与人群差异，需分别测量 | 不用性别/体型分类补身份判断；本人识别失败可立即改用系统认证 |

## 每类信号的边界

相貌只用于用户明确录入后的本地一对一模板匹配；不建立性别、种族、年龄、胖瘦或身高档案。
单个正面摄像头没有可靠的全身尺度；拍摄距离与姿势也会混入身高体型估计。
衣着易更换、遮挡或模仿，最多是当次人体跟踪的临时线索，不能决定解锁、锁机或追加认证。
首版不采集衣着统计。相貌模板也是敏感个人数据，应独立加密、删除和重新录入。

眼睛只检查当次是否睁开及注视目标，不保存阅读视线轨迹。动作可自选眨眼或轻转头；
有眼镜、眼部/颈部限制、面部差异的人可跳过面部路径，改用系统密码、Touch ID 或可用的设备认证。
注视判断未知时不能降低面部认证要求，也不能屏蔽替代入口。

语音默认关闭，主动选择后才开始一次短采样。可尝试新生成的随机短句，同时绑定挑战、采集时间、
同一脸和音画同步；原始音画只在本次内存中，取消/结束/休眠立即释放。
不后台学习日常对话，不分析语言习惯、情绪或健康，不录旁人声音建立模板。
公共场所直接换用无声方式；口音、失声、口罩、环境嘈杂只使该路径不可用，不成为异常人格画像。

原生 AVAudioEngine/AVFoundation 负责采集，Speech 只确认说了什么，不能冒充说话人身份认证。
若用 [SFSpeechRecognitionRequest](https://developer.apple.com/documentation/speech/sfspeechrecognitionrequest/requiresondevicerecognition)，
先确认 supportsOnDeviceRecognition，再设 requiresOnDeviceRecognition；不支持便结束该路径，不回退上传。
声纹 embedding 与防伪模型需另选合法权重、转换 Core ML 并在本机验证。随机句子并不能解决实时克隆或转发。
声音、嘴形、人脸及动作属于相关证据，不应当作四个独立因素简单相乘。

心率与健康数据默认不纳入，也不申请 HealthKit 权限。认证使用 Watch 的系统确认更直接。
[Apple workout 官方文档](https://developer.apple.com/documentation/healthkit/running-workout-sessions)
说明运动会话能产生高频心率并持续后台采集；不能为解锁伪装成运动会话，干扰真实运动与用户健康记录。
心率不能可靠证明佩戴者是本人，更不能把运动、咖啡、疾病或焦虑判成攻击。

熟悉位置由用户自选“在这里减少提醒”，用粗粒度本地区域，不读取系统“重要地点”历史。
位置、Wi-Fi、充电和随身配件仅是环境；旅行、出差、换充电器或设备掉线不得否决有效系统认证。
家里、办公室和设备附近也可能有攻击者；这些线索不能降低核心身份与防伪条件。

## 离位规则与恢复

“在场”“正在看屏幕”“本人”“可以解锁”是四个判断。照片、旁人和屏幕播放都可能让人体检测报告存在。
没有检出人，也可能是遮挡、逆光、关闭摄像头、另一块屏幕或正常离开视野；只能记未检出/未知。
传感器元数据不能证明输入未被伪造，Apple silicon 不自动把第三方采集链路变成 Face ID 的链路。

首版先以系统空闲锁屏兜底。可选离位模式不常开相机；在明确授权的短窗内，
两路持续证据、空闲时间与取消窗口齐全才提出锁屏请求。输入、人员返回或未知会撤销候选。
它不是防攻击者注入键鼠事件的机制，不能替代系统空闲政策；手机留在桌上也会降低该路径的覆盖。
已被强证据确认的盗抢走独立安全处理，不能拿离位取消窗口无限拖延。

[PresencePolicy.swift](../tools/presence-probe/PresencePolicy.swift) 已实现独立纯策略：
默认影子模式；当次可靠系统认证后按会话代次启用；30 秒空闲、至少 10 秒连续合格离开证据、5 秒取消时间。
这些是实验参数，不是已验证最优值。帧/设备证据须新鲜，乱序、采样断层、换会话、锁屏/休眠/状态未知撤销候选。
只有 requestSystemLock 请求，没有 unlock、rejectOwner 或锁屏成功状态；请求之后由权威系统状态核定结果。
43 条状态与边界检查已通过，未执行真实自动锁屏。

[原生相机探针](../tools/presence-probe/README.md) 用 AVFoundation + Vision 做低频人体检测，
仅已有授权且显式 --observe 才短采样。它未验证图像质量，故“未检出”**不能**接成策略的 noPersonInUsableFrame；
手机 verifiedDeparted 的可靠适配器也尚未完成，RSSI/广播/断连不得冒充该证据。
两处接线完成并通过误报评估前，自动锁屏保持关闭。

恢复必须始终可走系统密码、Touch ID 或系统允许的其它入口。行为基线不匹配时不能拦截系统认证，
不给用户建立必须“长得一样、穿得一样、表现一样”的恢复条件。有效恢复后先停止提示，不用异常样本立即污染基线。
防盗抢高风险设置可要求新鲜生物认证和延迟，但必须与日常恢复分开，不能为了防盗抹掉现有恢复能力。

## 能看见、能暂停、能删除

设置按用途独立选择相机、键鼠习惯、环境与语音，不设“一次同意所有传感器”。
相机扫描提示与系统指示灯一致；没有隐形录制。暂停立即停止采集，删除包括模板、统计与熟悉区域。
不用全屏“信任分数”，不显示“情绪异常”或“衣着不符”；需要确认时只说具体可观察的问题。
例如“光线不足，可用 Touch ID”，并保留系统密码入口。禁止把用户取消、权限拒绝或障碍记为攻击标签。

手表/手机/面部结果后台并行收集，动画保持原有进度与速度，不为统计重启翻盖弹簧。
使用减少动态效果、替代认证或关闭传感器的人保留同样清晰的反馈；不把额外动画当必经等待。
锁屏只画安全生成素材，只有系统实际解锁后才恢复新桌面画面。
