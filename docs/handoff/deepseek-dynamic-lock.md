# 交给 DeepSeek：离开就锁，回来就开

用法：先贴 [deepseek-input.md](deepseek-input.md) 里的“总则”，再贴这里的一个包。顺序：L1 → L2 → L4。
L3（身份实验）和 L5（代填密码）由主模型做。规格：`docs/dynamic-lock.md`，以它为准。

补充总则：

- **不拷代码。**PhoneKey（blue-lock-mac）和 BLEUnlock 的仓库里没有许可文件，只能照规格里写的事实独立实现。
- **锁只看断开，不看信号强度。**任何“信号弱了就锁”的写法都是缺陷。
- **这个包不碰密码。**不读、不存、不输入登录密码，不调用任何模拟键盘输入；那是 L5，由主模型做。
- 锁屏用系统公开的办法；具体用哪个，在报告里写清楚。

## L1：在场状态机（纯逻辑）

新文件：`prototype/Core/PresenceLock.swift`、`tests/PresenceLockTests.swift`、`tests/run-presence-lock-tests.sh`。

- **输入**：
  - 手机：连上、断开、读到回应、信号强度（dBm）；
  - 手表：同样四种（可以没绑手表）；
  - 摄像头：看到人、看不到人（可以没开）；
  - 键盘或触控板有输入；
  - 锁屏、解锁，以及这次锁是谁锁的（离开就锁 / 用户 / 系统）；
  - 当前时间（单调时钟，由调用方给）。
- **输出**：
  - 刘海状态：无、倒数（剩几秒）、取消；
  - 动作：收起私人 App、暂停播放、锁屏、继续播放；
  - “可以回来就开了”的判定，带原因。

规则（每条至少一个测试）：

1. 断开后先静默宽限 1.5 秒；宽限内重连并读到回应，什么都不发生。
2. 读不到回应超过 2 秒，算断开，走同样的宽限。
3. 宽限过后进入 10 秒倒数。倒数中有任何输入，或者重连并读到回应，都取消，刘海显示“不了”的状态。
3b. 因为输入而取消后，手机仍然断开时，要等连续 60 秒没有输入，才会再进入宽限和倒数。
4. 绑了手表时，手机和手表都断开才开始宽限；只断一样不锁。
5. 摄像头连续看不到人超过设定时长，也进入同样的倒数（摄像头没开就忽略这条）。
6. **信号强度再弱，只要连接还在，就不锁。**
7. 倒数结束时，动作顺序是：收起私人 App → 暂停播放 → 锁屏。
8. 回来就开，四条全满足才返回“可以”：
   - 这次锁是离开就锁锁的；
   - 重连后读到了回应（只收到广播不算）；
   - 信号强度连续 2 秒高于阈值；
   - 需要认脸时脸已认出（由调用方传入）。
9. 同一次锁定里，“可以”最多给 3 次。之后只能用 Touch ID 或密码。
10. 用户手动锁的屏，永远不给“可以”。
11. 解锁后，如果离开前有播放，就继续播放。

另外要测：时间倒流、重复事件、宽限中又断又连好几次、倒数刚好结束的那一刻有输入。

## L2：蓝牙监视（App 层）

新文件：`prototype/App/PresenceMonitor.swift`。只用 CoreBluetooth 公开接口。

- 绑定：扫描附近设备，列出名字和信号强度，用户选一台。保存的是系统给的设备标识，不用名字认设备；同名的设备要提示用户确认。
- 连接与保持：Mac 主动连接，发现“设备信息”服务（找不到就退回全量发现），每 5 秒读一次，确认连接活着。服务发现期间最多 6 秒不判断超时。
- 信号强度：只在锁屏期间每 0.5 秒读一次，用来判断回来没有；平时不读。
- 事件全部交给 L1，自己不做判断。
- 手表：同一套接口，作为第二台设备；连不上就在报告里写清楚卡在哪。
- 日志：只写事件种类和时间，不写完整的设备标识，不写读到的内容。
- 检查：`./build.sh --check`。报告里写 Aaron 怎么真机试：在 iPhone 的“设置 → 蓝牙”里关掉开关（控制中心的按钮不算真关），看 Mac 是否在约 11.5 秒内锁屏；然后带着手机走远再走回来。

## L4：刘海倒数、收起私人 App、播放、远程锁（App 层）

- 刘海倒数：`figure.walk` 手机走远了 · 10。取消时：`hand.raised` 不锁了。用已有的刘海面板和活动，不新建窗口。
- 收起私人 App：调用已有的“收进刘海”。私人 App 名单如果还没有，就先留接口，在报告里写明。
- 暂停 / 继续播放：用已有的音乐活动控制。
- `windowshade://lock`：注册 URL，收到后先收起私人 App，再锁屏；解锁后的“离开期间”摘要写“从 iPhone 锁上的”（摘要还没有的话，先留接口）。
- 设置：在刷脸解锁那一栏（还没有的话，在“权限与启动”栏）加三项：离开就锁（开 / 关，打开时选手机、可选手表）、回来就开（开 / 关）、回来的距离（近 / 中 / 远）。全部默认关。
- 检查：`./build.sh --check`。
