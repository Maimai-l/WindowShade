# A2 · hook 与本机 socket

**目标与验收：**两种 CLI 使用各自官方协议；无 App/超时返回无决定，让宿主按自身策略继续，而非自动放行。

**入口：**小命令放 code/tools/ws-hook/ 等 prototype 递归收集之外；构建脚本改动须在允许列表。配置只测临时 home。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation + Darwin，最低macOS14；`socket(AF_UNIX, SOCK_STREAM, 0)`、`bind`、`listen`、`accept`、`getpeereid(_:_:_:)`、`lstat`、`fstat`、`chmod`。socket0600、父目录0700；sun_path按 SDK 实际容量检查。配置和精确 JSON见 reference/hooks-and-app-server.md。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
enum HookReply: Equatable {
    case noDecision, allowOnce, deny
    func encode() throws -> Data {
        let payload: [String: Any]
        switch self {
        case .noDecision: payload = [:]
        case .allowOnce, .deny:
            payload = ["hookSpecificOutput": [
                "hookEventName": "PermissionRequest",
                "decision": ["behavior": self == .allowOnce ? "allow" : "deny"]
            ]]
        }
        var data = try JSONSerialization.data(withJSONObject: payload, options: [.sortedKeys])
        data.append(0x0A)
        return data
    }
}
```

## 坑与绕法
provider/event/version 分支不可混。返回 `{}`+换行+exit0表示无决定；PermissionRequest 的 allow 是真实放行，必须有匹配且已消费的一次授权。Claude无可提示 UI 时可能拒绝，不能保证总有“终端提示”。同 UID socket 客户端也未必是官方 CLI。

## 测试与真机
测分帧、超长、无换行、并发、对端断开、重复审批、120秒上限、锁屏；配置测试保留其他 hooks/未知字段，改动后 CAS 失败不覆盖。集成真实 CLI 与配置变更必须 Aaron 在场。

## 不做与未决
不读 transcript；不返回 updatedPermissions/acceptForSession；不把 config 日志/备份打包。参考附录的 macOS 长 socket 路径和崩溃清理规则。
