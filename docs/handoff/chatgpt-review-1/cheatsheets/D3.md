# D3 · 指挥状态视图

**目标与验收：**状态来自 D1；同一刘海内能识别草稿、等待、拒识、断连，显示层不作执行决定。

**入口：**App/NotchActivityView.swift 与主模型指定子视图；使用已有 Motion 令牌。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
AppKit/QuartzCore，最低macOS14。`NSTextField(labelWithString:)`、`NSView.addSubview(_:)`、`NSLayoutConstraint.activate(_:)`；公开刷新 `update(snapshot:)` 标 @MainActor。原包 `Core/NotchActivities.swift` 只能承载被仲裁后的展示。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import AppKit
@MainActor
final class ConductorStatusView: NSView {
    private let label = NSTextField(labelWithString: "")
    override init(frame: NSRect) {
        super.init(frame: frame)
        label.maximumNumberOfLines = 1
        label.lineBreakMode = .byTruncatingTail
        addSubview(label)
        label.translatesAutoresizingMaskIntoConstraints = false
        NSLayoutConstraint.activate([
            label.leadingAnchor.constraint(equalTo: leadingAnchor),
            label.trailingAnchor.constraint(equalTo: trailingAnchor),
            label.centerYAnchor.constraint(equalTo: centerYAnchor)
        ])
    }
    required init?(coder: NSCoder) { nil }
    func update(text: String) { label.stringValue = text }
}
```

## 坑与绕法
外部文本按纯文本显示，移除控制字符、限字节、可展开看全。动态项目名/模型名不受“8个字”死限。草稿可视和屏幕录制是不同能力，D3 不应为了显示文字申请录屏。假的脉冲/波形不可冒充真麦克风。

## 测试与真机
枚举每个状态截图并逐项看，断线/取消/锁屏后数据清掉；颜色外有文字/符号；125%/不同分辨率/外接屏。探针就在现有宿主，不新开产品 panel。

## 不做与未决
不要因原提示词“独立开发面板”新建第二个 UI 宿主；不可从 view 调后端 submit 或构造授权票。
