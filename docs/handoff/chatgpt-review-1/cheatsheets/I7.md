# I7 · 输入设置与许可状态

**目标与验收：**一处设置控制一处输入生命周期；显示未授权、未连接、不支持等真实原因，不开功能也不装钩子。

**入口：**原包 Preferences各输入栏目；gamepad行归入现有输入设备位置，不另起控制中心。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation/AppKit，最低macOS14；复用偏好、PermissionState、设备快照。`CGPreflightListenEventAccess()`、`CGRequestListenEventAccess()` 用于需要它的监听权限，`AXIsProcessTrustedWithOptions(_:)`用于辅助功能；只有用户点击启用后才请求。具体 tap/IOHID 需要哪项在macOS14/27验证。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
struct InputConsent: Equatable, Sendable {
    var selectedDevice: String?
    var enabled = false
    var hasPermission = false
    var compatible = false
    var sessionUnlocked = false
    var shouldInstall: Bool {
        enabled && hasPermission && compatible && sessionUnlocked && selectedDevice != nil
    }
}
```

## 坑与绕法
隐私 registry 未完成时先提供声明数据，不创建未登记读取。开关状态和运行状态分开：已勾选但没连接≠正在接管。撤销TCC立即清down latch和合成输入，不能继续显示“正常”。“只按页面打开才读”仅针对诊断页面，不应截断功能已获同意的事件。

## 测试与真机
测设置迁移、所有新输入默认关、开失败回滚、多个入口同步、不可用原因、本机权限撤销与重启。真实TCC弹框Aaron在场，禁止批量重置他的权限数据库。

## 不做与未决
不复制现有开关、不伪造读数；原规格没写的宏、配置导入导出、按钮编辑器不做。
