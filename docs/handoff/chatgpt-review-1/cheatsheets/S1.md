# S1 · 符号和简短说明

**目标与验收：**每行图标、标签和说明完整可访问；缩短的是重复措辞，不是风险告知和权限用途。

**入口：**App/Preferences.swift 及主模型逐个列明的设置文件；先生成真实行数清单。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
AppKit，最低 macOS 14；`NSImage(systemSymbolName:accessibilityDescription:) -> NSImage?`、`NSImage.SymbolConfiguration(hierarchicalColor:)`、`withSymbolConfiguration(_:)`。符号失败必须回退，不 force unwrap。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import AppKit
@MainActor
func settingsSymbol(_ name: String, label: String) -> NSImage? {
    let image = NSImage(systemSymbolName: name, accessibilityDescription: label)
        ?? NSImage(systemSymbolName: "gearshape", accessibilityDescription: label)
    return image?.withSymbolConfiguration(.init(hierarchicalColor: .labelColor))
}
```

## 坑与绕法
包内符号只在报告的 macOS27 上核过，不能证明 macOS14都有。“71条、39条”是历史计数。隐藏在 info 气泡中的危险动作说明仍须在用户做该动作时显露；文本不能靠颜色独立表达状态。

## 测试与真机
逐条输出旧→新→气泡完整文本→旧 preference key；确认行为/default没变。测深浅色、增加对比度、减少透明度、VoiceOver、长本地化与窄窗口；最低系统符号枚举测试。

## 不做与未决
不把字数限制作硬截断；不新造第二个设置框架；不把 faceid 图标用于自制刷脸。
