# I9 · 方向焦点

**目标与验收：**无鼠标也能在已有可见项间移动、确认、返回；稳定 ID 保证刷新后不会跳到错误对象。

**入口：**新增原包指定 Core 焦点文件；UI 接线仍由主模型负责。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation，最低 macOS 14；矩形策略可用 CGRect 的 minX/maxX/midX/midY。建议 `next(currentID:direction:items:) -> ID?`；过滤不可见、禁用、其他显示器。AppKit 接线使用 `NSWindow.makeFirstResponder(_:) -> Bool`。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
struct FocusNode {
    let id: String
    let x: Double
    let y: Double
    let enabled: Bool
}
enum FocusNavigator {
    // 坐标已归一为 x 向右、y 向下；这是最小中心距离策略。
    static func next(from current: FocusNode, nodes: [FocusNode],
                     dx: Double, dy: Double) -> String? {
        guard abs(dx) + abs(dy) == 1, dx * dy == 0 else { return nil }
        return nodes.filter {
            $0.enabled && $0.id != current.id && $0.x.isFinite && $0.y.isFinite &&
            ($0.x - current.x) * dx + ($0.y - current.y) * dy > 0
        }.sorted {
            let a = pow($0.x - current.x, 2) + pow($0.y - current.y, 2)
            let b = pow($1.x - current.x, 2) + pow($1.y - current.y, 2)
            return a == b ? $0.id < $1.id : a < b
        }.first?.id
    }
}
```

## 坑与绕法
示例只展示确定性中心距离，不是完整矩形重叠算法。正式策略先选方向半平面，再选投影重叠候选，再按距离、稳定 ID 打平。AppKit y 轴方向需统一。边缘不自动绕回，避免意外跳到批准。

## 测试与真机
测空表、删除当前项、同坐标、斜向、宽卡片、隐藏项、跨屏、RTL约定、键重复。真机键盘足够；审批出现前按住的 Return、遥控器 held-select 不能算新确认。

## 不做与未决
不抢系统全局方向键；普通焦点导航不能自动批准。焦点框、VoiceOver 标签和回退去向由主模型同宿主实现。
