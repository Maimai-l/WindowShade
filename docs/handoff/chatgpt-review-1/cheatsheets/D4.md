# D4 · 模式设置与已配对设备

**目标与验收：**默认不监听；切开关是显式生命周期事务，已配对设备清单只来自真实持久记录。

**入口：**原包指定 Preferences 与偏好文件；身份登记、配对 keychain 由主模型/D5 提供。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation/AppKit，最低macOS14。`UserDefaults.bool(forKey:)` 仅保存同意；密钥使用 Security `SecItemAdd(_:_:)` / `SecItemCopyMatching(_:_:)` / `SecItemDelete(_:)`，不能存在 defaults。新 setting key 是本项目接口，不是系统 API。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
struct ConductorPreferences {
    let defaults: UserDefaults
    var enabled: Bool {
        get { defaults.bool(forKey: "conductor.enabled") }
        nonmutating set { defaults.set(newValue, forKey: "conductor.enabled") }
    }
    // 保存设置不产生配对或审批权限；由上层显式事务开启监听。
}
```

## 坑与绕法
切关要停 Bonjour/监听/输入、清草稿和能力票、撤销远端控制租约；在途后端执行状态未知时不能声称已停止。删配对需要真实授权并撤销所有对应连接，不能只删一行显示。隐私 registry 不是“有就登记”的可选项。

## 测试与真机
测默认关、开失败回滚、关后无监听、退出重开、删设备时有待批任务、旧密钥重连失败。真实配对/删除要 Aaron 明确确认。

## 不做与未决
不写假设备，不显示不存在的模型档位，不加宏与快捷操作库。
