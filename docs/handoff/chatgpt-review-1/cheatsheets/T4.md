# T4 · 两项设置与共用状态

**目标与验收：**设置、快捷键、负一屏卡片读取同一个计时器；切设置不重置正在进行的计时。

**入口：**在原包范围内添加设置行与既有快捷键项；负一屏不持有第二个 timer。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation/AppKit，最低macOS14；`UserDefaults.object(forKey:)`、`integer(forKey:)`、`set(_:forKey:)`。快捷键复用项目已存在的注册器，不添加独立全局 tap。新默认快捷键为空。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
struct FocusPreferences {
    let defaults: UserDefaults
    var minutes: Int {
        get { defaults.integer(forKey: "focus.minutes") == 50 ? 50 : 25 }
        nonmutating set {
            guard newValue == 25 || newValue == 50 else { return }
            defaults.set(newValue, forKey: "focus.minutes")
        }
    }
    // 新键名只是示例；正式合并前先查仓库，不能替换已有键。
    var foldChat: Bool {
        get { defaults.object(forKey: "focus.foldChat") as? Bool ?? true }
        nonmutating set { defaults.set(newValue, forKey: "focus.foldChat") }
    }
}
```

## 坑与绕法
“专注时收聊天”原规格默认开；与输入拦截默认关是不同设置，不要误统一。正式键名由主模型查现有枚举后冻结。25→50只影响下一轮；当前轮变化须有明确产品决定。

## 测试与真机
测首次安装/已存在false/非法minutes/迁移；同一轮在两处显示一致；空快捷键不注册；重复点击开始只开始一轮。窗口收起验收依赖 T3，Aaron 在场。
