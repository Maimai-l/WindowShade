# T1 · 截止时刻与暂停原因

**目标与验收：**计时不随 tick 漂移。锁屏、睡眠、手动暂停重叠后，只有全部原因解除才恢复专注；休息到点结束，不自动再开专注。

**入口：**新增 Core/FocusTimer.swift；不要覆盖已有 Core/FocusSession.swift。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation，工程最低 macOS 14。纯 reducer 用 `reduce(state:event:now:calendarDay:) -> (State, [Effect])`（本包建议的新接口）。适配器用 Swift `ContinuousClock.now`、`Instant.duration(to:)`；睡眠期间也推进。自然日由 `Calendar.startOfDay(for:)` 单独注入，不能用单调秒数除以 86400。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
// 只展示暂停原因与截止时刻；完整阶段转换由 T1 补齐。
struct FocusDeadline {
    enum Reason: Hashable { case manual, locked, sleeping }
    private(set) var reasons: Set<Reason> = []
    private(set) var deadline: Double?
    private var remaining: Double = 0
    init(duration: Double, now: Double) {
        precondition(duration.isFinite && duration > 0 && now.isFinite)
        deadline = now + duration
    }
    mutating func set(_ reason: Reason, paused: Bool, now: Double) {
        guard now.isFinite else { return }
        if paused {
            guard !reasons.contains(reason) else { return }
            if reasons.isEmpty {
                remaining = max(0, (deadline ?? now) - now)
                deadline = nil
            }
            reasons.insert(reason)
        } else {
            guard reasons.remove(reason) != nil else { return }
            if reasons.isEmpty { deadline = now + remaining }
        }
    }
}
```

## 坑与绕法
必须区分手动、锁屏、睡眠三种暂停原因。晚到的到点事件应按原 deadline 转入休息，再处理休息也已到点的情况。跳过不算完成；同一轮完成只计一次。暂停、结束、隐藏时不得留下逐秒计时器。

## 测试与真机
纯逻辑：锁→睡→醒仍锁；手动暂停→锁→解锁仍暂停；重复通知；到点和锁屏同刻的明确顺序；跨午夜、时区切换；休息睡两小时。真机：Aaron 在场做一次睡眠/唤醒，比较系统时间改动前后剩余时长。

## 不做与未决
不接窗口移动和权限；不加统计图、长休息或自动下一轮。日期策略和同刻排序写进测试，不让执行模型自行选。
