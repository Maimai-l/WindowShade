# A3 · 会话显示与回到终端

**目标与验收：**只在已有刘海显示真实会话；去看看可以回到正确 App，批准在 A4 未接入前不可执行。

**入口：**接已有 NotchActivityView/Controller 与 WindowBrowser 恢复入口。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
AppKit，最低macOS14；`NSRunningApplication(processIdentifier:)`、`bundleIdentifier`、`isTerminated`、`activate(options:) -> Bool`。精确窗口动作继续复用当前窗口身份/恢复桥；不另开一条标题匹配 AX 搜索。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import AppKit
@MainActor
func activateAgentApplication(pid: pid_t, expectedBundleID: String) -> Bool {
    guard let app = NSRunningApplication(processIdentifier: pid),
          app.bundleIdentifier == expectedBundleID, !app.isTerminated else { return false }
    // 仅激活 App。精确窗口需走已有 WindowShade 窗口身份与恢复入口。
    return app.activate(options: [])
}
```

## 坑与绕法
PID 会复用，窗口标题可重复且会变。优先已绑定的稳定窗口身份+进程身份复核；没法证明就只激活 App。待批准是排他的交互层，不能只增加 agent 的普通活动 priority。锁屏时标题、命令、项目名立即清空。

## 测试与真机
测两终端同名、pid过期、窗口退出、会话完成/等待切换、多屏、系统锁屏；所有假数据仅 DEBUG+显式探针。A4 未就绪时只测试“不允许/去看看”。

## 不做与未决
不提前启用 allow；不生成无真实音频的波形；不重新抓屏和新建屏幕录制授权。
