# L4 · 倒数、收起与锁屏效果

**目标与验收：**倒数能取消；折叠/暂停音乐失败不能无限阻止锁屏；只有系统锁状态回执才记为锁定。

**入口：**接原包指定现有 Notch、窗口折叠、音乐入口。锁操作后端由主模型先提供并验证。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation/AppKit，最低macOS14。自定义 `SystemLockAdapter.requestLock(sessionID:)` 是拟新增项目协议，不是 Apple API。已有 `Private/LockSpaceBridge.swift` 仅证明锁屏空间上的窗口能力，不证明调用了系统锁。锁通知也不能作为身份验证。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
// 一次效果协调；lock effect 仍必须交给真实、已验证的主模型适配器。
struct LockEffectGate {
    private(set) var issued = false
    private(set) var isCancelled = false
    let session: UUID
    let deadline: Double
    mutating func poll(now: Double, stillAway: Bool, cancelled: Bool) -> UUID? {
        if cancelled { isCancelled = true }
        guard now.isFinite, !issued, !isCancelled, stillAway,
              now >= deadline else { return nil }
        issued = true
        return session
    }
}
```

## 坑与绕法
不要把启动屏保/熄屏当锁。外部 windowshade://lock 不证明来源是 Aaron 的 iPhone，不能授予自动解锁归属。现有 playPause 是 toggle，可能把已暂停音乐播起来；没有显式 pause 和恢复所有权时跳过音乐联动。

## 测试与真机
纯逻辑：deadline恰好取消、折叠超时、重复lock effect、外部URL、系统未确认。真机Aaron在场：默认输入仍可用、锁屏一次、解锁后只恢复本轮拥有的窗口；操作退出无悬空遮罩。

## 不做与未决
不写/缓存/输入登录密码；不让锁屏外观替代真正锁定；未验证锁后端时交付 UI+假适配器并标阻断。
