# I2 · 私有多触点桥

**目标与验收：**先验证 ABI 与生命周期，再把有界触点快照交给 I1；出错立即停用这一个来源，原有输入继续。

**入口：**新增 Private/MultitouchBridge.swift；公开数据模型独立于私有结构。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Darwin+CoreFoundation+IOKit，工程最低macOS14；私有 ABI 无公开最低版本保证。`dlopen`完整 framework可执行路径、`dlsym`；符号/候选 C 签名/96字节历史布局见 reference/private-abi.md。示例只做存在探针，绝不读未知内存。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Darwin
// 只检查动态库是否存在，不把历史头文件冒充 macOS 27 的安全 ABI。
final class MultitouchLibrary {
    private let handle: UnsafeMutableRawPointer
    init?() {
        guard let h = dlopen("/System/Library/PrivateFrameworks/MultitouchSupport.framework/MultitouchSupport",
                             RTLD_NOW | RTLD_LOCAL) else { return nil }
        handle = h
    }
    func hasSymbol(_ name: String) -> Bool { dlsym(handle, name) != nil }
    deinit { dlclose(handle) } // 注册回调的正式桥必须先 stop、unregister、排空。
}
```

## 坑与绕法
旧头文件中的注册与注销 callback 签名自己也不一致，不能抄 cast。回调指针生命周期只在本次回调内；固定容量复制，禁止指针跨 Task。非 Sendable设备对象不穿队列；先 stop/unregister，证明回调排空，再释放上下文/库。

## 测试与真机
先编译 C shim验证sizeof/offsetof，再真机单指、两指、掌心、插拔、睡眠、100次启停；缺符号/不同family/超长帧时不崩。改写中键/轻点之前 Aaron 在场先做只读探针。

## 不做与未决
不把符号存在当 ABI 验证，不用 @unchecked Sendable 掩盖数据竞争；原头未确认可复用许可，本包未抄实现。完整接触序列与中键down/up平衡通过后才启用转换。
