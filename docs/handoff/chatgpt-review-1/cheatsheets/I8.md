# I8 · DualSense 适配

**目标与验收：**只在选定手柄明确启用时控制 Mac；让位、关闭、断连时释放按键、关闭扳机阻力，不留下锁死状态。

**入口：**GameController桥；交 I1/I9统一动作。系统Space交互由主模型I4提供，不能拿直接换Space冒充跟手手势。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
GameController，工程最低macOS14。`GCController.controllers()`、`physicalInputProfile as? GCDualSenseGamepad`、`GCController.shouldMonitorBackgroundEvents`（进程级）；`leftTrigger/rightTrigger: GCDualSenseAdaptiveTrigger`、`setModeFeedbackWithStartPosition(_:resistiveStrength:)`、`setModeOff()`；`touchpadPrimary/touchpadSecondary/touchpadButton`。不是 `adaptiveTriggers` 属性。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import GameController
@available(macOS 14.0, *)
func setPreviewResistance(on controller: GCController, enabled: Bool) {
    guard let pad = controller.physicalInputProfile as? GCDualSenseGamepad else { return }
    if enabled {
        pad.rightTrigger.setModeFeedbackWithStartPosition(0.6, resistiveStrength: 0.25)
    } else {
        pad.leftTrigger.setModeOff()
        pad.rightTrigger.setModeOff()
    }
}
```

## 坑与绕法
系统不提供一个可直接相信的“其他App正在用这只手柄”布尔值。游戏让位须保守前台规则+手动排除并验证。坐标0,0不能独立证明没触点。扳机阈值要latch+hysteresis，只提交一次；释放取消预览，不撤销已经提交的动作。

## 测试与真机
Aaron在场分别USB/蓝牙、不同固件、两手柄、前台游戏切换、断连时扳机按住、低电量、休眠。所有受支持效果须实际手感确认；电量未知不写0%。

## 不做与未决
不安装PS键系统动作处理，不偷切麦克风，不修改全局手柄配置。Swift例子仅设置效果，没证明后台事件、触点或haptic在本机可用。
