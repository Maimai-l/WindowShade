# T2 · 刘海里的番茄钟

**目标与验收：**已有宿主渲染同一 T1 状态；展开、收起、锁屏、暂停时动画和刷新都正确停启。

**入口：**Core/NotchActivities.swift、App/NotchActivityView.swift、App/NotchActivityController.swift；接主模型仲裁接口。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
AppKit + QuartzCore，最低 macOS14；`CAShapeLayer.strokeEnd: CGFloat`、`CABasicAnimation(keyPath:)`、`CALayer.add(_:forKey:)`、`removeAnimation(forKey:)`、`CATransaction.setDisableActions(_:)`。剩余时间来自 T1；别直接混用系统 uptime 和 layer 时间轴。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import AppKit
import QuartzCore
@MainActor
func animateFocusRing(_ layer: CAShapeLayer, from: CGFloat,
                      remaining: TimeInterval, reducedMotion: Bool) {
    layer.removeAnimation(forKey: "focus.progress")
    let start = min(1, max(0, from))
    CATransaction.begin(); CATransaction.setDisableActions(true)
    layer.strokeEnd = reducedMotion ? start : 1
    CATransaction.commit()
    guard !reducedMotion, remaining.isFinite, remaining > 0 else { return }
    let animation = CABasicAnimation(keyPath: "strokeEnd")
    animation.fromValue = start; animation.toValue = 1
    animation.duration = remaining
    animation.timingFunction = CAMediaTimingFunction(name: .linear)
    layer.add(animation, forKey: "focus.progress")
}
```

## 坑与绕法
现有 store 的 kind 优先级不等于蓝图的六层仲裁。环动画设置 model layer 最终值，暂停重建而非只停文字。Core Animation 也消耗渲染资源；隐藏、屏幕关闭、锁屏立即 remove。展开 mm:ss 需要秒级文案刷新，紧凑态才按分钟。

## 测试与真机
测跨分钟最后60秒、展开收起、Reduce Motion、窗口换屏、锁屏抢占、自然完成仅提示一次。测空闲/显示动画/隐藏后三态 CPU、唤醒、WindowServer。

## 不做与未决
不接 T3 的真实窗口动作；不建常驻60Hz Timer；休息无限呼吸与能耗验收冲突时收敛为有限动画，不声称免费。
