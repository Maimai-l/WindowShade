# I5 · 实体 Siri Remote

**目标与验收：**按真实 HID down/up 归一按钮；只静音选定设备的自有映射，关功能和崩溃后可恢复。

**入口：**IOHID桥与映射事务拆开；匹配Apple0x05AC和原包实测PID候选，不把VID/PID当独占设备身份。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
IOKit.hid，最低macOS14；`IOHIDManagerCreate`、`IOHIDManagerSetDeviceMatching`、`IOHIDManagerRegisterDeviceMatchingCallback`、`IOHIDManagerRegisterDeviceRemovalCallback`、`IOHIDManagerRegisterInputValueCallback`、`IOHIDManagerScheduleWithRunLoop`、`IOHIDManagerOpen` / `IOHIDManagerClose`；`IOHIDValueGetElement`、`IOHIDElementGetUsagePage/Usage`、`IOHIDValueGetIntegerValue`。映射工具 `/usr/bin/hidutil property --get/--set` 用 Process+arguments，不用 shell拼接。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
import IOKit.hid
final class RemoteHIDReader {
    private let manager = IOHIDManagerCreate(kCFAllocatorDefault, IOOptionBits(0))
    // 不自动调用；Aaron 明确启用选定设备后才进入。
    func openAppleRemote(productID: Int) -> IOReturn {
        IOHIDManagerSetDeviceMatching(manager, [
            kIOHIDVendorIDKey: 0x05AC,
            kIOHIDProductIDKey: productID
        ] as CFDictionary)
        return IOHIDManagerOpen(manager, IOOptionBits(kIOHIDOptionsTypeNone))
    }
    func close() { _ = IOHIDManagerClose(manager, IOOptionBits(kIOHIDOptionsTypeNone)) }
    // 匹配回调、单设备选择、run loop 和 hidutil 所有权事务由正式桥补齐。
}
```

## 坑与绕法
TN2450说明映射会随服务移除/重启丢失，但不保证你的所有consumer usages可改为无事件。原包按键表是候选硬件记录；同PID两设备会误伤。变更前保存原映射，写入合并值；恢复仅当仍等于自己写入值，保留后来用户修改。

## 测试与真机
Aaron在场逐键按/松/长按、休眠和重连、其他键盘/第二台遥控器不受影响、强杀恢复、外部工具同时改映射。核对原始 HID是否还到达，不能由论文/README代替真机。

## 不做与未决
本包不读0xFA麦克风，不接触面，不发送系统密码，不偷开全局抢占模式。配对可能影响原AppleTV使用，操作前确认。
