# I3 · 滚动 tap 和回退

**目标与验收：**只有明确启用且来源可靠的输入才改写；设备未知、故障、安全输入或其他工具接管时原样返回。

**入口：**新 tap 参考 App/HabitKeys.swift 的生命周期，但不复制其未经本机复核的权限假设。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
CoreGraphics+CoreFoundation，最低macOS14。`CGEvent.tapCreate(tap:place:options:eventsOfInterest:callback:userInfo:) -> CFMachPort?`；`CGEvent.tapEnable(tap:enable:)`、`CGEventTapCallBack`；`CFMachPortCreateRunLoopSource`。合成滚动用 `CGEvent(scrollWheelEvent2Source:units:wheelCount:wheel1:wheel2:wheel3:)` 并设置 sourceUserData。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import CoreGraphics
// tap 回调 ABI。演示透传，不在这里创建任务、日志、AX 查询或阻塞锁。
let inputTapCallback: CGEventTapCallBack = { _, type, event, _ in
    if type == .tapDisabledByTimeout || type == .tapDisabledByUserInput {
        // 正式桥只设置一个受控故障标志，管理队列负责撤销，不能在回调中重装。
        return Unmanaged.passUnretained(event)
    }
    if event.getIntegerValueField(.eventSourceUserData) == 0x5753_4933 {
        return Unmanaged.passUnretained(event)
    }
    return Unmanaged.passUnretained(event)
}
```

## 坑与绕法
flags不是设备ID。tap安装条件须覆盖“精细/侧键单独开”而不只平滑/方向。disabledByTimeout/UserInput 后本次回调透传，管理队列撤销/通知，不无限重启。合成事件打标并全链路排除，滚动整数/固定/点单位必须一致。

## 测试与真机
纯逻辑模拟自己的合成事件不再进弹簧、丢帧、反向、剩余冲刷。真机Aaron在场：权限拒绝/撤销、Secure Input、不同鼠标并用、游戏、浏览器不支持侧键、主动停tap仍有原输入。p99只报测量值。

## 不做与未决
不后台申请权限；不在callback写日志/AX查询/Task分配；无证据的App不发 Cmd+[ / Cmd+]，避免把快捷键送错目标。
