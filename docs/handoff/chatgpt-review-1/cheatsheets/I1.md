# I1 · 输入纯逻辑

**目标与验收：**拆成可单测的滚动、来源分类、拖动、触点、遥控键和模式判定六个子任务，统一输出动作。

**入口：**原 I1 六个 Core 文件分别提交补丁；事件类型先冻结，再给 D1/I2/I3/I5 使用。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
Foundation，最低 macOS 14。骨架为解析临界阻尼弹簧：`add(_:)`、`step(dt:)`、`settle()`。公共输入模型需单位、坐标方向、deviceToken、contactID、phase、monotonic time、confidence；unknown 是正式来源类型。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import Foundation
// 位置趋近累计输入 target，输出本帧位移；不是完整滚轮适配器。
struct ScrollSpring {
    private(set) var position = 0.0
    private(set) var velocity = 0.0
    private(set) var target = 0.0
    let omega: Double = 20
    mutating func add(_ delta: Double) {
        guard delta.isFinite else { return }
        target += delta
    }
    mutating func step(dt: Double) -> Double {
        guard dt.isFinite, dt > 0 else { return 0 }
        let old = position, y = position - target
        let c = velocity + omega * y
        let decay = exp(-omega * dt)
        position = target + (y + c * dt) * decay
        velocity = (velocity - omega * c * dt) * decay
        if abs(position - target) < 0.00001 && abs(velocity) < 0.00001 {
            position = target; velocity = 0
        }
        return position - old
    }
    // 反向/关闭时如何分配剩余位移由适配器明确决定，不悄悄丢位移。
    mutating func settle() -> Double {
        let residual = target - position
        position = target; velocity = 0
        return residual
    }
}
```

## 坑与绕法
CGEvent 的 continuous/momentum 标志不能证明具体物理设备；IOHID 枚举也不能直接关联某个 CGEvent。未确认来源的事件原样放行。反向时处理旧残余和新输入的规则要写清；同向保持速度。触点按完整接触会话判断，不能先认出三指，再把第四指当下一次。

## 测试与真机
测输入积分≈输出位移+残余、不同刷新率、反向、NaN/Inf、长帧、零 dt；轻点150ms/.25s/1.5mm边界；第四指晚到、丢 ended、拔设备、短长按互斥。所有硬件映射先标待确认。

## 不做与未决
不把 VID/PID 直接当每事件来源；不在本包读 HID/AX/TCC；1.5mm 需真实传感器尺寸，不能套屏幕像素。
