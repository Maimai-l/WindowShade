# M1 · 原生菜单收拢

**目标与验收：**菜单仍走原有 selector/快捷键，只减少入口；普通态、Option态、开发态都可核对，旧功能不消失。

**入口：**只改 App/MenuBarController.swift；先确认被移走项在设置中确实存在。 路径以原包 `code/prototype/` 为基准，`Core/` 新文件遵守原包允许列表。

## API 与最低系统
AppKit，最低 macOS 14；`NSMenuItem(title:action:keyEquivalent:)`、`isAlternate: Bool`、`keyEquivalentModifierMask: NSEvent.ModifierFlags`、`image: NSImage?`。alternates 相邻、相同 keyEquivalent、不同修饰符；保持 target 生命周期。

## 最小骨架
下列是原创边界示例，不是完整功能。编译范围见 [validation.md](../validation.md)；Apple SDK 片段没有在本次环境编译。

```swift
import AppKit
@MainActor
func makeSettingsAlternates(target: AnyObject, settings: Selector,
                            about: Selector) -> [NSMenuItem] {
    let a = NSMenuItem(title: "设置…", action: settings, keyEquivalent: ",")
    a.target = target; a.keyEquivalentModifierMask = [.command]
    let b = NSMenuItem(title: "关于 WindowShade", action: about, keyEquivalent: ",")
    b.target = target; b.keyEquivalentModifierMask = [.command, .option]
    b.isAlternate = true
    return [a, b] // 必须相邻插入同一个 NSMenu。
}
```

## 坑与绕法
没有 SUFeedURL 不等于开发构建。开发项用编译开关隔离；伪造/漏填 plist 不能暴露探针。12项应按当前可见的可操作一级项计算，标题/分隔线/原窗口恢复区的例外写清。Option时设置和关于互换须测键盘与鼠标。
