# 主模型裁决 · 2026-10-04

来源：Aaron 在复核会话里连续勾选；依据是 Grok 会话 [`Grok goal setup process`](../../..) 里 G1–G3 交付报告的「需要主模型决定」。不签名、不发布、不替换日用 App。

|编号|题目|决定|立刻意味着什么|
|---|---|---|---|
|D01|G1 截图|**现在看。** W01 可用窗口是 TextEdit 空白文件／临时窗口。|主模型启动本机构建出的未签名二进制，只动 TextEdit；菜单、设置各页、浅色和深色都截。|
|D02|番茄钟设置两行名字|**维持界面：**「番茄钟」「专注时收起聊天窗口」。|不改成规格里的「专注时长／收进刘海」。隐私表引旧名也不手改。|
|D03|Option 菜单|**改成 `isAlternate` 替换。**|「检查更新／欢迎／开发」不再插入多一行；允许顶掉被替换的那一行。Grok 或主模型在菜单分支改，改完要能用 Option 键验收。|
|D04|G2 未核对钩子|**现在做隔离探针，不接生产钩子。**|滚轮产品号、多触点布局、遥控器静音映射：开关继续灰；探针写到 `tools/probes/`，结果未核过就不装事件 tap／HID。|
|D05|I4 / I6|**1.x 都做。** I4 中键接标题栏；I6 遥控器麦克风。|从「保留给以后」改成要做。I4 可先接已有中键逻辑到标题栏手势，默认关。I6 麦克风未核映射前同样只探针、开关灰。|
|D06|W01 真机窗口|**只用 TextEdit 空白文件／临时窗口。** 手柄可以另议，本次未授权。|禁止动 Finder、浏览器、未保存窗口、日用 WindowShade。本地只读会话仍要空项目／临时目录。|
|D07|W02 番茄钟窗口效果|**按终态：专注收聊天、休息收全部。**|设计不再缩成「只聊天」。施工仍要 TextEdit／用户点名的聊天窗口验收；缺身份就跳过并显示部分未处理，不枚举未知 App。T3 控件在真机通过前仍显示「现在只计时」。|
|D08|W04 批准|**原生一次普通命令批准，和 hook 配置预览都做。**|默认只读入口不变。普通命令：完整审阅 → 系统认证 → 授权账 consume 一次。hook：预览、比旧值；**写用户配置必须 Aaron 再点头一次**，测试只用临时 home。|
|D09|W07 配对|**等 Aaron 指定 iPhone／配件再做真配对。**|未指定前不写 Keychain、不配网。指定后主模型做密码学与身份，不交给 Grok。|
|D10|W08 CarPlay|**只做隔离探针，有证据再谈。**|目标保留，不广告能接收，不拿遥控按键冒充。|
|D11|W09 锁与身份|**允许人脸实验，不接系统解锁。** 声纹本次未开。|锁态继续只读系统事实。人脸不写入解锁后端。声纹模板不登、不做。|
|D12|planned 隐私行|**进隐私页，标「还没读」。**|轻点、遥控器、配对密钥等 planned 行可见且灰色；真的读到再改状态。声纹因 D11 未开，可显示但必须是还没读。|

## 仍禁止

发布、签名、推 Release、改更新源、替换 `/Applications` 里正在用的 App、对未点名的窗口做试验、把未知写成成功。
