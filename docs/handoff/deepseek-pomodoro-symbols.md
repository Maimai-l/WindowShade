# 交给 DeepSeek：番茄钟与符号优先

用法同 [deepseek-input.md](deepseek-input.md)：先把那份的“总则”贴上，再贴这里的一个包。顺序：T1 → S1 → T2 → T4。
交出去之前，先提交 `docs/pomodoro.md`、`docs/design-system.md`、`docs/copy-guide.md` 和本文件。

补充总则：**奥卡姆剃刀。**番茄钟只有规格里写的东西；不加白噪音、统计图、导出、任务名、长休息、窗口、菜单栏图标、通知横幅。
要加任何一样，先停下问。

## T1：番茄钟计时（纯逻辑）

- 新文件：`prototype/Core/FocusTimer.swift`，配测试 `tests/FocusTimerTests.swift` 和 `tests/run-focus-timer-tests.sh`。
- 状态：空闲 / 专注 / 休息，再加“已暂停”。时长：25 + 5 或 50 + 10。
- **按截止时刻计时**：存截止时刻，不累加 tick。时间由调用方传入（单调时钟）。
- 事件：开始、暂停、继续、跳过、结束、到点、锁屏、解锁、睡眠、唤醒。规则：
  - 锁屏或睡眠时，专注暂停，截止时刻顺延；休息照走。
  - 专注到点后自动进入休息；休息到点后回到空闲，**不自动开下一个**。
  - “今天完成几个”跨零点清零（日期由调用方给）。
- 输出：
  - 刘海文案：“18 分”，最后一分钟写“0:42”；
  - 下一次需要醒来的时刻：专注时按整分钟，最后一分钟按秒；
  - 要触发的动作：收进聊天、全部收进刘海、放回、提示音。
- 测到：上面每条规则；跨零点；暂停后继续的剩余时间；睡了 2 小时醒来时休息已经结束。

## S1：设置改成符号优先（App 层，只改文案和图标）

- 规则见 `docs/copy-guide.md` 第 7 条，符号表见 `docs/design-system.md` §4.11。
- 改 `prototype/App/Preferences.swift` 和相关设置页：
  - 每一行前面加一个圆角色块里的 SF Symbol（hierarchical 渲染）；
  - 副标题压到一行（约 16 个字），说不完的放进 `info.circle` 按钮弹出的小气泡；
  - 名字照 copy-guide 词汇表。
- 现在有 71 条副标题，39 条超过 20 个字。逐条给出“改前 → 改后”的对照表，放进报告。**意思不能丢**，丢掉的内容要进气泡。
- 不改任何行为、开关的默认值、偏好的键名。
- 检查：`./build.sh --check`；`tests/run-appkit-tests.sh` 里和设置有关的测试（例如 SettingsNavigationTests）照样通过。

## T2：刘海里的番茄钟（App 层）

- 在已有的实时活动里加一种 `focus`。排序：录音之后、隔空投送之前。先读 `prototype/Core/NotchActivities.swift`、`prototype/App/NotchActivityView.swift`。
- 三种样子：
  - 紧凑：左边进度环（专注是番茄红，休息是绿），右边是 T1 给的文案；
  - 展开（停在刘海上）：大字 mm:ss、“今天第 3 个”，以及暂停 / 跳过 / 结束三个圆按钮（`pause.fill` `forward.end.fill` `stop.fill`）；
  - 休息：一圈慢慢呼吸的光环，下面写“看看远处”。
- 进度环和呼吸都用 Core Animation（从现在动到截止时刻），不在主线程逐帧算。“减少动态效果”打开时，不呼吸，只显示数字。
- 刘海展开那一排的末尾加一个 `timer` 按钮，用来开始。
- “收进刘海 / 全部收进刘海 / 私人 App 名单”的接线**不做**，留接口给主模型（T3）。
- 检查：`./build.sh --check`。

## T4：设置两项、快捷键与负一屏卡片（App 层）

- 文案照 `docs/pomodoro.md` 的“文案”一节。
- 检查：`./build.sh --check`。
