# 工单 02　Mac 窗口故障矩阵

使用用户明确允许的测试应用与可恢复窗口；不要操作尚未保存的重要内容。记录实际 OS 构建、SDK/Swift、架构、屏幕配置、权限、源文件哈希和方法。下表是待执行验收，不是本轮已通过的设备结果。

|编号|操作/故障注入|必须观察到|不合格时|
|---|---|---|---|
|M01|正常收起后展开，再立即重收同窗|每次完成只归各自 transaction|停用候选入口，查绑定和投递 stamp|
|M02|故意让首个完成回调再发一次收起|旧通知不关闭/确认新请求|查整批取出和投递时逐个复核|
|M03|读取 AX 几何暂时失败|显示未确认，保留原 journal 与人工恢复入口|禁止把 unknown 改成 true|
|M04|原方法 offscreen，读回仍可见或未知|不会悄悄再最小化|查 salvage 条件与记录方法|
|M05|原方法 minimized，明确仍未最小化|仅同策略有限重试；重试前核对身份|禁止不断重复写 AX|
|M06|收起中切 Space 或拔主显示器|旧 presentation 结果不被接受|不把旧结果换当前 stamp 重发|
|M07|等待/排队时锁屏后再解锁|旧成功不复活，锁中无自动恢复|检查原 ledger epoch 与锁态入口|
|M08|后台巡检未回时展开并重收|旧 snapshot 不清理新状态|保留 batch + transaction 双检查|
|M09|一个应用 AX 很慢，另一个正常|已返回应用本轮结果能先处理；旧过时结果丢弃|记录下一轮仍等待的边界，不伪造可取消|
|M10|活着应用的原生缩高窗口多次读不到尺寸|不能只因失败计数清理|确认真实退出和未知分开|
|M11|撤 observer 后旧通知排队到达|旧 routeID 不再路由到新 observer|禁止复用路由编号|
|M12|伪造/重放取消最小化提示，但窗口仍最小化|重新读取实际状态，不直接当用户展开|检查严格 CFBoolean 读取|
|M13|应用显示提示到达时目标应用仍隐藏|不清理恢复入口|查实际 isHidden 和当前 stamp|
|M14|普通隐藏窗口在当前屏幕列表缺席|不能仅凭缺席宣布成功|核对所属具体隐藏方法的观察|
|M15|Quick Look 有意关闭、自有窗口 orderOut|按独立特例核对；失败显示未知|不能将特例推广到一般窗口|
|M16|原生 resize 响应慢|即时核对或原 proxy fallback，应用不中途重入安装|记录视觉差异，别恢复嵌套 RunLoop|
|M17|AX 权限撤回后恢复|旧结果不通过；新操作重读权限/上下文|不因 enabled=true 复用旧结果|
|M18|人工尝试恢复未知窗口|实际观察恢复结果，journal 未被假成功删除|保留未解决状态和可见提示|

特别记录 unknown 后窗口真实处于哪里、overlay 是否能找到、人工恢复是否有效。不要把窗口卡片截图当作原窗口已经恢复的证据。若私有隐藏方法在具体 OS 不再可核查，应关闭该方法并保留其他经过验证的路径，不改动用户未保存窗口来制造好看的结果。
