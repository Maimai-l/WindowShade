# 工单 03　首帧和旧调用者回归

代码入口：Effects/EffectFrameAwaiter.swift、Effects/EffectFrameSource.swift、WindowBrowser/WindowBrowserAppDelegate.swift、tests/DuoCoreTests.swift。后两项生产调用者的完整平台图仍需 Mac 编译；本份只修改了首帧 helper 与浏览器契约注释。

先运行 `run.py --suite frame`。原 DuoCoreTests 在严格 Swift 6 下应原样编译通过；若错在 Apple SDK 进口类型，保存具体调用点、编译器和 SDK，不把所有捕获对象加 unchecked Sendable。

在 Mac 验证开始捕获后立即关闭、同窗重建捕获、暂停中失效、读取首帧时取消，以及应用退出。过期帧不得交给新动画。返回非 nil 仍不代表整条 ScreenCaptureKit capture graph 生命周期已经正确，需核对原 producer generation、stream 释放和观察者销毁。

浏览器连续点同窗、切选中项、关闭页面后晚到结果都要测。客户完成回调现在排队，不能在发出收起调用后的下一行假定选中列表已经更新。false 应显示当前操作未确认或保留界面供核对，不能直接判断窗口已经恢复，也不能无提示重复收起。

整批回调中第一个客户回调撤销事务时，后续回调不得采用已失效的成功。用新 regression 的受控顺序核对，再在真实浏览器入口重做；不要通过批量异步延时掩盖顺序。
