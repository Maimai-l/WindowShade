# 第七份：接通本地助手使用流程

交付基线：第六份统一包的 `candidate-repo/`，1145 个文件。当前不是公开仓库 HEAD，不是已编译的发行版本。完整 v7 候选已经叠好，直接从统一包 `candidate-repo/` 开始；不要再逐份执行 part1 至 part7。

这次已有实际 `WS2OwnedLaunchController`，不再要求你重新设计这个类。它连接本地选择、版本预检、独立配置、登录、真实模型目录、会话创建与恢复、一次提交、流式显示、停止和锁态撤销。Runtime 强持有它；设置页“编程会话…”进入同一刘海宿主。新的 C 监督端口负责唯一子进程回收，实际正常退出入口也已经连接更新器与助手的联合门槛。

## 先交到用户手上的范围

本地入口目前是**只读查询**。它拒绝请求提升权限的命令和文件操作。此前的完整命令审阅、原生认证与授权账保留在独立适配器中，但没有接成新入口的默认允许路径。不能为了显示“全能编程”而把默认 host 换成自动批准，也不能把这条只读阶段说成整个 WindowShade 2 已完成。

操作顺序已经落实到源码：打开入口 → 本地选择项目和可执行文件 → 勾选运行与账号使用确认 → 点击启动 → 核对固定版本和配置 → 必要时点击登录 → 选择实际返回的模型 → 输入文字并点击发送 → 看匹配的最终结果 → 停止本轮或断开。关闭页面不等于断开；锁屏、睡眠或禁用会撤销并清除界面私密内容，解锁不自动启动。

## 执行者只需按三步推进

第一步，运行 `tests/run.py` 的 core/native/flow 三套测试，再按 `tests/regressions.py` 运行旧回归。命令在 README 中。受控后端只存在于测试目录，不能安装成 Codex 或伪装真实账号。

第二步，在 Mac 隔离副本运行 `tests/run-mac-check.sh`，这是整 App 优化编译、Metal 和链接，不只是 parse。先解决实际 SDK 错误，保留 Swift 6、完整并发检查、警告视为错误，不删除 Sparkle、仲裁或认证源码绕过编译。不要把 `Native/` 从复制或目标输入中漏掉。

第三步，按 `workorders/01-Mac与真实CLI验收.md` 用用户明确允许的空测试项目、实际 0.153.0 CLI 和独立账号状态运行。实际 `config/read` 若缺少所需字段，入口会拒绝；这时记录原始结构、按固定 schema 研究，不用恒 true、宽权限配置或修改测试期待来绕过。

## 本轮以后怎样算完成

`COMPLETION-CONTRACT.md` 把本地试用、允许路径、整个原项目分开。停止增加泛用 Manager；后续改动必须消除表中的一个具体源码缺口，或取得一个真实平台证据。不能用第八份、第九份这种序号代替完成条件。详情看 `REMAINING.md`，它没有删除远端接收、窗口效果、手柄、身份、能耗和影片等原目标。

## 不做什么

不改真实 home 配置、不自动启动工具、不运行真实远端命令、不签名、不发布、不改更新源。本次测试只在自己的临时目录运行假后端和原生子进程。用户真实设备与账户没有参与。旧配对/SRP、HID、窗口恢复和影片材料仍是历史交付，不因打入新 ZIP 就算本次完成。
