# 第七份后仍缺什么

本地助手不再缺启动控制器和基本页面接线；本轮已有候选源码，不能再把这部分笼统写为“待设计”。但没有 Mac 与真实 CLI 验收，不能称已经可用或已发行。

|项目|本轮结束时状态|具体下一项|
|---|---|---|
|本地只读助手流程|候选接线完成；18 个受控后端流程场景通过|Mac 整 App 编译；真实固定 CLI 的配置投影、登录、实际查询与停止|
|原生视图|同一 Island 入口、实际模型/草稿/回复/停止已接|布局、输入法、焦点、短屏/多屏、关闭重开与点击授权实测|
|正常进程监督|Linux 实际 spawn/reap/同组停止通过，PROC04 修复|Mac waitid/进程组行为，其他 Foundation/Sparkle 子进程并存；真实正常退出|
|异常退出或脱离组子孙|没有给出保证|独立 supervisor/service 或明确受限的产品策略；不能把同组测试称全树安全|
|配置可信度|独立目录、版本/身份检查、有效投影拒绝策略已有|可信 CLI 来源、受管理配置、真实版本字段、实际只读沙盒与工具边界|
|原生允许审批|旧候选适配器保留；新入口默认拒绝|真实 scope、完整目标、Touch ID/consume、断连/锁态及允许消息端到端；文件等权限另外完成|
|手柄/遥控/HID/鼠标/多触点|无本轮生产桥推进|现有 gate 接当前可见列表和真实设备；ABI 与 usage 仍需证据|
|番茄钟窗口效果|已有纯计划，真实端口仍缺|Fold typed completion、AX 隐藏/恢复、unknown/迟到补偿、journal 接线|
|配对接收|原有候选和背景保留|SRP 固定依赖与实测、Listener/OPACK/session、Bonjour profile、Keychain 安全重配、原生对端互操作|
|身份/系统锁|本轮只使用既有 AuthorizationService 锁态门槛|自有人脸模型/活体/误识率、BLE 身份动作、可靠系统锁解锁后端原任务仍未完成|
|能耗/隐私/全菜单设置|新增隐私登记已加入候选|33 类旧登记与本轮 delta 联审；同机能耗；所有旧入口、Option、设备偏好撤销回归|
|影片与发行|没有本轮新影片/签名/发布|17 项真机素材、声音授权/混音、正式构建、最终观感；发布另取用户授权|

当前没有可靠工期估计。可试用本地流程的判定依 COMPLETION-CONTRACT 的 A 表；整个项目依 B/C 与原蓝图。不能因为完成了 A1 就删除其余源码任务，也不能把“代码已连接”降格成继续新增相同工单来拖延验收。
