# Mac 与真实 CLI：已有接线的验收单

## 1. 构建，不先加功能

使用全新候选，不在实际工作区覆盖文件。运行 `bash part7/tests/run-mac-check.sh candidate-repo`。保存整个 stdout/stderr、退出码、xcodebuild/SDK/Swift/OS 版本。Native/WS2Child.c 必须用目标架构与部署 macOS14 编译并参与主 App 链接。模块表在 Native/module.modulemap；别仅把 swift 文件复制过去。Watchdog 不需要这套模块。

不要把 App/Updater.swift 的旧逻辑整体换掉。此次只增加一个异步终止回复端口，并由 Runtime 合并。不要修改发布版本、更新源或签名身份。--check 不启动 App、不发行。

## 2. UI 的确切入口

现有补充设置页点击“编程会话…”。若找不到按钮，检查 WS2SupplementPane 的实际页加载链与 NotchController/系统锁态，不新增第二个入口来隐藏问题。入口创建的 view 由现有 Island 租约持有，Runtime 已持有控制器。

测试 620×560 展开尺寸、外层滚动、长中文路径、字体缩放、带刘海/无刘海、主屏移除。确认底部发送/停止能滚动到，剪裁不遮住同意文案。输入中文组字时按发送不得提交，Return 只换行；鼠标、键盘与滚动不抢审批的租约。

## 3. 用真实 CLI，不用本包假文件

由用户本地选择固定 0.153.0 的实际可执行文件，空临时项目、没有项目/祖先 .codex/.agents；明确确认运行。该要求是初版保守限制，不能为方便测试去删用户目录。版本不匹配时停止，不自动安装或升级。

记录 config/read 的结构和配置来源，按源文件策略确认各必需项。如果该版本不返回 features 或返回新的 wrapper，当前入口会关闭。先对照固定 schema 和真实版本说明，再做最小适配；不得放宽为缺字段默认为 false。记录可能存在的系统/受管理来源；没有证明其收窄行为前只在隔离测试账户使用，不宣布这是安全沙盒。

点登录会跳系统浏览器，这是用户主动操作。不要把验证码、auth.json、token 或完整账号对象附入交付日志。成功后只记录登录状态及方法，模型目录可以记录公开 ID。点击一次“列出这个空测试项目有什么内容”的只读请求，确认模型回复真实到达。若 CLI 因工具策略而拒绝列目录，记录真实拒绝，可改为不需要工具的无副作用文本查询；不能悄悄开放 shell 来制造通过。

## 4. 必测顺序

|编号|操作|必须观察到|
|---|---|---|
|MAC01|未勾确认直接尝试启动|无子进程、无假会话|
|MAC02|实际启动和登录|真实版本、目录、账号与模型状态逐步更新|
|MAC03|双击发送/组合输入|只提交一次有效草稿|
|MAC04|流式回复时上滚|阅读位置不被强制拉回底部|
|MAC05|停止本轮|RPC 回复仍为停止中，最终事件才结束|
|MAC06|关闭页面再打开|同一实例，不重复启动、不丢真实状态|
|MAC07|锁屏或睡眠后晚回调|scope 撤销、私密视图清空、解锁不重启|
|MAC08|换真实目录后恢复旧 thread|跨项目拒绝；同目录关联才允许|
|MAC09|退出登录/取消登录|不把取消等同于无凭据；重新连接重读事实|
|MAC10|版本预检挂起后取消/退出|版本子进程也等回收，不立即释放启动槽|
|MAC11|终止直属进程、子孙保留输出|原 PROC04 通过，不接迟到内容|
|MAC12|更新器下载期间正常退出|更新器与助手两个条件都满足，reply 只一次|
|MAC13|监督错误/超时|不假称已清理，取消正常退出或明确显示不确定|
|MAC14|CLI 请求额外权限|此入口发送 decline，无 Touch ID 旁路，无自动 allow|
|MAC15|本次诊断未开启/已开启|默认不保留 stderr；开启后仅有界尾部，锁态清空|

测试真实“停止”只针对自己的子进程。不要杀用户终端里原先启动的工具，不扫描所有同名进程。每项记录实际 OS/架构、输入、观察、是否替身、源码哈希和失败日志。不能以一张截图替代生命周期记录。

## 5. 回滚

若 Mac 整体不能构建，先回到完整 v6 候选，不能只删 C 模块而保留导入它的 Swift。若已有用户代码改动，按 manifest 三方恢复，不覆盖其改动。运行时禁用只读入口不会替代已有进程清理；先明确断开并取得回收证据，再撤入口。独立账号目录保留给用户处理，不能为“干净回滚”自动删凭据。
