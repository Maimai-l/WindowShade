# 其余目标：复用既有部件，提交真实调用者

本单不假称这些实现已经交付。本轮主要跨越本地 CLI 和停止链，其他生产路径仍需完成。按原蓝图保留各目标，不让一个私有协议是否可用阻塞不依赖它的本地功能。

## 手柄与原生列表

保留 WS2DeviceActionHost / WS2GameControllerBridge / WS2SelectionModel。下一笔代码必须是在当前可见会话/模型列表里的实际 sink 和唯一 Runtime 实例，而不是第四套 selection reducer。只有当前租约、稳定 item ID、snapshot revision、neutral 状态和本次附件启用都满足才消费一次票据。中文组合输入或审批出现，取消 held 与票据。发送草稿仍只由可见的本地确认路径进行，不向全局焦点发送 Return。

## 窗口效果

保留 FocusEffectPlan/Executor，但先修改原 Fold 的完成落点，形成匹配 run、transaction、identity、revision 的 typed result。真实 AX 读取缺失记 unknown，不沿用 nil 就成功的 helper。增加真正隐藏/恢复端口，再接计时事件；不要调用有 toggle 语义的 tuckAll 代替幂等动作。旧动作晚完成须有核对和补偿，不用新的 UUID 掩盖老窗口仍在屏外。持久 journal 与原恢复机制共用，不创建第二个恢复管理器。

## 配对接收

保留原有 M1–M6、Pair-Verify、PeerRepository 和 ConnectionBudget。下一笔代码应是实际 Listener owner、受限 codec、session 消息与验证后路由。先完成 SRP 库固定依赖、Swift 实测和异构互测，再启动广告。原生 Remote 是否接受 Mac 服务端、确切 TXT/profile、设备输入格式仍待证据，不填猜测值。密码学门控不能用假后端的布尔通过替换，客户端能控制 Apple TV 不证明相反方向成立。

## 原生允许审批

保留 WS2OwnedCodexSession+Authorization 与既有 ApprovalHost。任何新生产入口都必须交回真实项目/配置范围、完整命令审阅、真实授权账消费和当前 writer 的绑定，而不是只是换 hostFactory。受控后端校验序列化不能证明 Touch ID、安全范围、CLI 真正采纳权限。文件/网络/长期规则仍分别完成自己的可信显示与决定。

## 系统锁、身份与影片

继续按前六份的事实门禁：系统锁态、BLE 身份、人脸模型/活体/误识率与数据最小化分别验证。不把账号登录、心率、名字或设备发现当系统解锁。影片仍需要真实录屏与声音，不能将本地测试界面拍成已经可配对/解锁的宣传。

每个方向最后提交：原文件差异、实际调用关系、释放路径、与本轮候选的组合构建、真实证据或明确不可用原因。没有外设时把不可用原因接在实际 UI 中，继续可独立工作的路径；不要再以“多写一份背景”替代这些生产调用者。
