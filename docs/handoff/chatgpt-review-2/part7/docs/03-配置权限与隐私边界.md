# 配置、权限与隐私边界

## 运行程序的同意早于版本检查

`--version` 本身就在执行用户选择的文件。因此选择文件、点击启动前的确认不能被“只是探测版本”绕过。没有同意不创建子进程。版本输出符合固定字符串只证明这个程序自称该版本，不证明签名、供应链或善意。本轮没有自动下载、升级或替用户选择可执行文件。

项目路径、程序路径都来自本地文件选择器。远端消息不能改变 cwd 或启动参数；native spawn 不经过 shell 拼字符串。目录记录规范路径、设备号、inode；程序另记大小和修改时间。这是会话错配检查，不是防同 UID 攻击的强沙盒，也不能消除检查与使用间的文件系统竞态。

## 独立配置实际保存在哪里

点击启动后，候选创建 `~/Library/Application Support/WindowShade/OwnedCodex-v1/` 下的 home、codex、tmp。目录 0700，配置文件 0600，要求同 UID、非链接。已有配置若被改动，停止启动而不是覆盖。没有读取或复制原 `~/.codex` 的凭据和配置。

运行环境是明确的 HOME、CODEX_HOME、TMPDIR、系统 PATH 与 locale 列表，不继承 API key 等任意环境变量。当前策略明确选择 CLI 的文件凭据存储方式；官方资料说明该方式使用 CODEX_HOME 下的 auth.json。[S4](../sources/SOURCES.md#s4) 因此不能写“所有内容仅在内存”：凭据和 CLI 自己的会话文件会留在独立目录，关闭刘海页面或断开不删除这些文件。用户注销由 CLI 的真实 RPC 处理，本次没有操作真实凭据。

## 配置收窄有用，但不能过度承诺

配置明确指定 read-only、on-request、user reviewer、禁用 web_search、shell_tool、unified_exec、shell_snapshot。新建/恢复 thread 和每次 turn 再携带已固定的权限参数；默认 host 对额外权限请求只会拒绝，不会调用授权账或自动批准。

项目及祖先存在 .codex/.agents、已知 /etc/codex 配置存在时，初版保守拒绝。它没有删除 AGENTS.md，也不把提示词当权限。官方配置有多层优先顺序，独立 CODEX_HOME 不等于排除系统、受管理和服务端的所有配置来源。[S5](../sources/SOURCES.md#s5) 因此握手后还校验 config/read；缺少必要字段、取值不符或外部能力非空就关闭，不默认为安全。

这个服务端投影仍不能证明选中的程序诚实，也不能追溯阻止其启动时已经执行的恶意动作。Mac 的受管理配置、当前版本返回哪些字段、沙盒实际行为均未实测。生产准入必须依赖可信可执行来源和真实运行验证。read-only 不等于只可读项目；工具网络禁用也不等于模型服务不联网。

初版只读入口的存在不取消后续普通命令一次性批准目标。旧认证适配器仍走完整审阅和 AuthorizationService.consume。只有完成真实范围、权限展示与原生认证验收后，才能另行开放这一入口；不能仅修改工厂默认值来宣称完成。

## 原始 JSON 先拒绝歧义

RFC 8259 提醒重复对象成员会导致实现间行为差异；本项目选择比一般兼容更严格的拒绝策略。[S6](../sources/SOURCES.md#s6) 检查发生在 JSONDecoder 形成字典之前，包括嵌套对象、转义后的键相同、非法 UTF-8、孤立 surrogate、额外尾随值、深度和节点预算。

`"id"` 与 `"\u0069d"` 必须视为重复。Swift String 的等价比较还会保守拒绝规范等价的 Unicode 键，这不是宣称所有 JSON 实现都必须如此。请求 ID 的整数/字符串类型保留；同一消息同时出现 result/error 或 method/result 会直接关闭连接。帧长度与原有 outbox 上限继续有效。

## 新增数据去向

新增登记在 `sources/privacy-signals.json`，并同步进候选 `docs/handoff/round2-part7/`。本轮实际测试没有采集真实用户账号、项目内容、外设或生物信息。

|数据|读取时机|保留与去向|
|---|---|---|
|项目/程序身份、路径|本地选择、启动和相关复核|控制器内存；路径显示本地，不自动分析目录内容|
|版本 stdout|明确点击启动|最多 8 KiB，校验结束清空；不是登录或工作结果|
|账号是否可用、模型目录|真实协议返回|本次连接内存；不把邮箱用于显示或日志|
|草稿/回复|本地输入及 stdout|各有上限的本地内存；用户点击发送会交选中的 CLI，可能转给模型服务|
|stderr|本次显式 opt-in|64 KiB 内存尾部，可能仍有敏感内容，无自动导出或上传|
|CLI 凭据和自己的历史|用户实际登录或运行时|独立 CODEX_HOME 磁盘目录；由 CLI 管理，不谎称关闭页面即擦除|

清空 Swift Data/String 不等于密码学级内存擦除。拒绝传感器、未登录、未装外设不会触发重试采集。之前的人脸、声纹、心率、BLE 项目没有因为这份新增一个账号入口就获得任何身份授权能力。
