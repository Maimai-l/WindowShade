# 工单 05：合并、回滚与其他原目标

输入链与窗口链是两组可分别撤回的源码改动，但都依赖现有v7共享合同。manifest里每个路径带base SHA与新SHA；base-sources保存修改前的原文本。实际工作区更晚时三方合并，保留用户的正确新改动并记录语义冲突。stage只用于精确v7，拒绝覆盖现有输出与错基线，不是通用合并器。

先合并Core合同、实际host/view/Runtime等输入单元并做整App构建，再合入窗口证据单元做原恢复回归。可各建一个本地提交；不要同时升级CLI、引入SRP主干依赖、改发行版本或换整个UI框架。默认关闭设备不会让编译错误消失，回滚须恢复全部相互引用文件。

本地助手沿用固定0.153.0协议，只读入口继续拒绝额外权限。配对接收仍需要固定SRP依赖、Swift实际互测、Keychain初始化/安全重配、唯一Listener、受限OPACK/session、真实Bonjour profile和原生客户端证据。不得为“本次进度”开一个无认证的临时监听器，或把Mac作为AppleTV客户端的成功推导为接收原生Remote成功。
