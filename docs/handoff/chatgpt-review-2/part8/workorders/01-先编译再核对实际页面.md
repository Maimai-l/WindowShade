# 工单 01：隔离构建和真实页面

路径是 prototype/Core/WS2DeviceActionContracts.swift、WS2VisibleListInput.swift，App/WS2DeviceActionHost.swift、WS2GameControllerBridge.swift、WS2ModelPickerView.swift、WS2AppRuntime.swift、WS2IslandCoordinator.swift、WS2OwnedSessionView.swift、WS2OwnedLaunchController.swift。新增 Core 合同必须与原桥的 typealias 同时合入，不能只换 view。Swift源文件由原 build.sh 纳入，Native/WS2Child.c 仍参与原有进程链接。

运行本包 tests/check-build.py 后，在 Mac 运行 `bash tests/run-mac-check.sh /绝对路径/candidate-repo`。脚本只在隔离复制中做原 build.sh --check，不签名、不启动、不发布，排除 local-codesign.env。保存 SDK/Swift/OS 构建号和完整错误。Linux 的78表示未运行。

编译失败先检查 handlerQueue 可选性、NSApplication 通知、NSTableView delegate隔离和原私有返回类型。以真实SDK错误修源，不建立虚假的 Cocoa 模块或删掉 affected 文件。修复后重跑实际文件的组合测试；不能退回 Swift5 消音。

用户允许测试实例后，从补充设置“编程会话…”进入原只读会话，使用匹配版本和本地独立配置，再打开“选择模型…”。初始未登录/尚无目录时不显示虚构模型，不为演示填入测试 fixture。没有真实账号时可以完成构建及页面空态验收，但不能标为已执行真实模型。

依次检查520×420、带/不带刘海、短屏和不同缩放，滚动长模型ID，鼠标键盘选择、返回后草稿保留，输入法组字途中按钮不跳页，关闭重开不启动第二个会话。页面失焦后再点击回来，本地按钮可用，但手柄保持停用。文字A/B需按具体设备核对，不把物理图形差异当错误路由。

回滚输入单元时一并回退这些互相引用的文件，保留第七份Owned流程和C监督模块。关闭入口前先stop活跃host，不能通过直接丢强引用代替回调释放。没有本次用户授权，不启动真实CLI、更不消耗账号额度。
