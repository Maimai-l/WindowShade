# T1 / T2 / T4 施工单

本份已经把核心、偏好、快捷键、工具入口和原生卡片接到同一个运行时。请在 Mac 验收这些已写代码，再补明确缺失的窗口效果和可见性接线，不重新写第二个计时器。

## 当前文件与入口

Core/FocusTimer.swift 的 `configure(preset:tuckChatEnabled:)` 更新下一轮设置；App/FocusTimerHost.swift 的同名入口再发布变更。runtime.open() 成功取得岛的host后在idle时start；toggleFocus()是快捷键的唯一入口。WS2FocusSettingsRows使用两个固定UserDefaults键。GlobalShortcuts id36默认nil，Preferences已加recorderRow，EventTap热键只转发runtime。

`LaunchpadToday` 和 `NotchActivityView` 的工具表已增加 focusOpen，NotchActivityController 接到 ws2FocusAction。确认其它 switch 保留既有入口；不能删唯一入口来满足菜单项个数。

## 执行顺序

1. 合成候选并 `build.sh --check`；录一个25/5开始后改50/10的截图/状态输出，deadline不能改变。
2. 测同一轮在菜单、工具按钮、快捷键、卡片之间切换，runID只有一个；暂停原因叠加和休息结束行为符合决定表。
3. 给现有活动的可见性回调接 host.presentation：卡片展开→expanded，真的可见紧凑活动→compact，整个功能不可见→hidden。不能根据是否存在一个弱引用就推断屏幕上一定可见。
4. 在负一屏原有卡片容器补 idle 番茄钟卡，直接显示预设和开始动作；读取同一host。不加任务名输入，不弹设置，一按开始。
5. 由主模型负责的T3窗口执行器绑定 focusWindowEffects，并使用 WS2FocusWindowOwnership 收据。成功后才把设置中的收聊天控件启用。nil或空实现均不具备资格。
6. 执行效果的提示音/窗口恢复遵循当前effect枚举，权限拒绝或窗口消失只影响该效果，计时不崩溃。记录真实成功与失败，不把已排队当已改变窗口。
