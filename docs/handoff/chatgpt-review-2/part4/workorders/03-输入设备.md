# I3 / I5 / I8 施工单

先合入 Core/WS2DeviceInputGate、App/WS2GameControllerBridge 和已有 GamepadMapping。build.sh 已增加 GameController framework。原始 SDK 摘录在 candidate/docs/handoff/reference/mac-facts-2026-10-03.md；属性签名用它与实际 SDK 比对。

## 公共手柄链先做完

应用 owner 创建一次 bridge，environment 每次读取真实 unlocked/sinkReady/前台游戏状态/输入域，emit 路由到现有 typed action dispatcher。把 devicesChanged 发布到原输入设置页，按 attachment UUID 绑定复选框；不存在的设备不能保持一个看似已配对的行。打开此功能才 start；用户选择设备且 sink就绪才 setEnabled。

在用户切会话/输入域、租约撤销、锁屏、睡眠、原应用退出和前台变化时调用 environmentChanged/suspendAll/stop 对应方法。不能只依赖 NSWorkspace.sessionDidResignActive。emit(.cancel) 要真的取消下游 held/录音状态；返回空结果而让下游还以为按钮按住，验收不通过。

可新增 `prototype/App/WS2InputSettings.swift` 用来承载这段设备列表，但保留既有设置页入口；不要新建独立偏好窗口。Desktop pointer/scroll 输出先接前份现有桌面效果 reducer，再接单一系统执行器，绝不由设备回调任意发送 shell 或审批 JSON。

## 参数与按钮文案

默认“未启用”。无权限写“需要在系统设置中允许输入访问”；sink未就绪写“动作接收器尚未接入”；游戏/未知前台写“当前应用未准入，已暂停控制”；断开写“已断开，重新连接后需再次启用”。这些是状态文案，不能显示“认证失败”来混淆设备许可与人的身份。

GamepadMapping 现有参数不在这一轮重新调一遍。先记录USB/蓝牙、设备型号、屏幕缩放、前台应用，再针对一项参数调试。反馈默认为零；完整归零测试之前不打开 feedback 调用者。

## HID 与鼠标分支不能借用手柄通过记录

继续写 `prototype/App/WS2HIDRemoteBridge.swift` 和 `prototype/Support/WS2HIDRemapRunner.swift` 时，按 exact设备匹配、非独占回调、设备级比较后写入/回滚实现。不要把 WS2HIDButtonMap 当成有监听生命周期的桥；它只返回候选按钮语义。

继续写 `prototype/App/WS2MouseInputBridge.swift` 时，先保证未知来源直通、合成事件防环、tap禁用清理和权限撤销，再接平滑算法。来源还不能判定时，不主动吞事件。私有多触点 ABI 未知则继续不准入，不写推测的触点结构。

## 必测矩阵

|ID|操作|必须结果|
|---|---|---|
|P4-IN-01|连接两只同名手柄|两个attachment；均默认关闭|
|P4-IN-02|按住A或偏转摇杆再启用|无立即动作；归零后新动作才生效|
|P4-IN-03|desktop按住后切conductor/review|cancel先于新域；不能沿用press确认|
|P4-IN-04|正在录音时断开|停止该来源采集，草稿不自动发送|
|P4-IN-05|当前进入游戏/未知前台|运动task停止；其他应用正常接收输入|
|P4-IN-06|给一台设备施加反馈再关功能|只清这台本桥自己的反馈；无遗留阻力|
|P4-IN-07|另一工具改过hidutil映射|撤销不得覆盖它的新值|
|P4-IN-08|未知HID usage /未知滚轮来源|保持系统原行为|
|P4-IN-09|静置5分钟与手柄断开|无本桥周期运动task；用实际采样报告CPU/wakeups|

“没有设备”时交回可运行探针/程序和缺失字段，不编造VID/PID或录音能力；继续推进不依赖这台设备的其它工作。
