# 与第三份候选相比

本份是overlay整文件替换，不能把新旧同名Swift文件并排放进prototype。精确范围由manifest/patch/FILE-MAP决定。

计时模型新增pending/active配置分离，修复中途设置更改导致的时长/窗口恢复语义；新增两项偏好控件、无默认绑定热键、工具入口和同一host的进度发布。T3未接不伪装窗口效果已工作。

新增Companion有界帧、服务端Pair-Verify、分方向记录加密候选。首次Pair-Setup、持久化和协议服务没有被这几个类代替。新增合成Python向量及待Mac执行的CryptoKit测试。

新增命令review快照、精确目标、新输入门控和原生审阅/授权交接host，Wire提供精确pending校验的一次性响应。原授权账没有被替换，allow仍未接入生产owned writer。文件/规则审批明确不准入。

新增每attachment输入准入、换域取消、候选公开GameController桥；补真实API方向与反馈归属决定。HID map不是监听器，另外几个输入桥仍列为源码缺口。

共享岛增加content尺寸、物理摄像头避让、弱所有权、过期/屏幕变化处理和原生认证租约接线；会话/指挥卡采用同一接口；修改草稿发送意图为发送最新编辑文本。没有另建浮窗，也没有把view展示方法等同于live后端已接通。

新增56项总决策、5份专题背景、5份施工单、API/协议来源边界、隐私增量登记和实际验证记录。旧未完成清单保留历史，但当前状态以第四份REMAINING为准。
