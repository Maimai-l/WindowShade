# 工单 06　窗口隐藏恢复的真实端口

## 已有基础

`Core/WS2FocusEffectPlan.swift` 管串行计划和归属，`Support/WS2FocusEffectExecutor.swift` 调异步 port。旧真实入口在 `App/FoldTransaction.swift`、`App/FoldCompletion.swift`、`App/FoldExit.swift`。具体函数和行号在 code-map。本包没有实际 AX adapter，不能把一个空 perform closure 标成能力就绪。

## 待新增文件

建议 `prototype/App/WS2FocusWindowPort.swift`，由 AppDelegate 的既有窗口管理能力提供操作，不自行建立另一套窗口列表。仅允许它把真实 typed 结果映射回 FocusEffectExecutor。需要给 FoldCompletion 加带完整 transaction 身份的等待接口，旧 Bool API 留给旧调用者，不做全局替换。

## 一次 tuck 的完整绑定

保存 `Identity(pid, processStart, windowID, windowGeneration)`、timer run、effectGeneration、beforeRevision、foldTransactionID 和 waiter token。建立 waiter 必须早于可能同步完成的真实动作。completion 的捕获值不可在后续从最新 shaded[id] 补读成“这次事务”，否则旧回调会冒领新状态。

执行前检查 mayCommit，确认窗口仍在允许集合、未被手动更改、系统状态允许。用具体隐藏动作，不调用切换式 tuckAll。动作后用三态观察核对；旧 hideTookEffect 中 `nil -> true` 的结果不能生成回执。缺观察证据映射 unknown，暂停该目标并要求恢复核对。

## 恢复与异常

恢复只消费匹配本轮回执的窗口，比较 liveRevision 与 afterRevision。手动移动/展开/重新收起优先，立即取消本程序的自动恢复归属。超时不等于动作没有发生；晚到完成需要按旧 attempt 做补偿核对，不能触发新 timer phase 的成功。

port 不能永久挂起。建议为一次观察/动作链设明确截止，并在到期时返回 unknown；截止值先按原 FoldVerifier 的真实重试安排和 Mac 测量确定，不把原 30 秒 waiter 兜底当交互延迟目标。取消等待不取消外部 AX 已经接受的动作，继续保留需要核对的记录。

锁屏、睡眠、App 退出、崩溃恢复分别测试。跨重启恢复必须与现有 journal 集成并重新识别窗口，不能持久保存旧 AX 引用或复用 PID。写 journal 失败时停止新的自动效果，计时仍可继续。

## 设置接线

真实 port 准入完成后才把 Focus 设置中的效果项变为可选。未完成时显示“仅计时”；不把不可用开关呈现为已生效。修改预设只影响下一轮，关闭卡片不停止计时，单一 host 不变。

## 验收结果

至少跑两应用、多窗口、多屏、全屏/Space、最小化、目标退出、手动改位置、锁/睡眠与中途退出。每例保存开始身份、事务号、观察三态和最终结果。能看到卷帘条不代表真实窗口已隐藏；恢复坐标正确但焦点错误也应单列失败。先保证原窗口回归，再启用自动专注效果。
