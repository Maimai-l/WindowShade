# 工单 04　手柄接到当前可见列表

## 复用与新增

复用 `WS2DeviceActionHost`、`WS2GameControllerBridge`、`WS2SemanticInputRouter`、新 `WS2SelectionModel` 与同一 Island。修改已有 `WS2AgentSessionView`、`WS2ConductorView` 的列表区域，不另造窗口。需要时新增 `prototype/App/WS2NativeSelectionAdapter.swift`，负责 NSView 差量和 typed sink；本包没有宣称这个适配器已经写完。

## 一次显示绑定一个上下文

为该视图保留一个 SelectionModel。得到真实数据快照后 replace(items)，把 resulting revision 写入当前输入环境的 targetRevision。输入处理取视图当下的 revision，不能沿用页面刚打开时的版本。selectedID 与实际高亮行一致，鼠标选择也更新同一模型。

为 device host 提供真实 `sink.ready`、`environment` 和 `execute`。当前视图不可见、没有 current lease、系统在锁中或列表失效时 ready=false。motionReady 与普通导航分开，窗口运动端口没接好时不能因为列表可用便启用运动。

## 具体动作表

|语义意图|本地调用|条件|
|---|---|---|
|上一项/下一项|SelectionModel.move(-1/+1, expectedRevision:)|当前快照，跳过禁用行，不循环|
|鼠标选择|select(id:expectedRevision:)|确切稳定 ID|
|打开当前项|reserveActivation → 再核对输入 lease/context → consume → typed open(itemID)|不发送系统 Return|
|取消页面|Island.dismiss(ifShowing:)|只能关闭本视图|
|中断助手|明确的 conductor intent → 当前 owned turn → interrupt|不与普通列表确定混用|
|审批确认|禁止从这个 sink 发出|必须走完整 review 和本机认证|

列表变更、退出、锁屏、切页或设备撤销调用 model.revoke，取消 device host 旧 held 状态。重新启用设备不能补发上一轮按住的按键。已经失效的 activation 直接拒绝，不能重新取“现在选中的项”补救。

## UI 与参数

初版不新增自动连发参数，使用项目已有重复节奏；需要连续滚动时专门测试边界。若用户正在中文输入，不把组合候选确认当提交草稿。长草稿在现有可编辑视图显示，禁止截断后的摘要作为真实发给助手的内容。只通过实际 model/list 填充模型与 effort。

## 验收

先用键盘和鼠标跑同一模型，再连接单个真实手柄：上下、到边界、列表重排、当前项删除、禁用行、快速双击、按住后拔线、切页后松开、进入审批时按 A、锁屏后回来。用稳定 ID 记录实际动作次数，不记录私人标题。只有列表路径通过，窗口运动和指挥提交能力仍不能自动标绿。
