# 台式 Mac、外接摄像头与盒盖模式

2026-09-30。用户明确要求 Mac mini / Studio + Studio Display、MacBook 盒盖 + 外接屏也可认证。
此前只允许内置相机的首版限制已撤销。安全目标保持；不能把“有盒盖传感器”设成认证前提。
本次交付候选发现/显式选择和显示目标绑定，完整系统解锁与锁屏呈现仍待接线和真机验证。

## 支持矩阵与触发

| 使用组合 | 相机与触发 | 不作为必需条件 |
| --- | --- | --- |
| MacBook 开盖独立使用 | 内置相机；开盖/系统唤醒触发短扫描 | 固定开盖角度、速度或充电方式 |
| MacBook 盒盖 + Studio Display | 已登记的显示器相机；外屏唤醒/系统锁屏出现触发短扫描 | 内置相机、掀盖动作、内置麦克风 |
| Mac mini / Studio + Studio Display | 已登记的显示器相机；系统唤醒或用户明确启动 | 盒盖传感器、MacBook 的运动传感器 |
| iMac | 内置相机；系统唤醒/用户启动 | MacBook 的角度与运动特征 |
| 任意 Mac + 其它带相机屏幕或 USB 相机 | 用户登记后逐设备验证质量、注视、防伪与延迟 | 仅品牌名、USB ID 或相机类型即获信任 |
| 任意组合无可用相机 | 系统密码、Touch ID、系统允许的 Watch 等路径 | 先找相机或先打开 MacBook 屏幕 |

[Apple Studio Display 支持说明](https://support.apple.com/en-gb/111102) 确认 Mac 可使用显示器内置摄像头。
[Apple silicon 外设许可说明](https://support.apple.com/en-us/102282) 说明盒盖使用前需允许显示器、键鼠等连接。
不降低系统外设许可策略来换取便捷。只有视频输出、没有相机数据，或相机暂不可用，保持未知。
MacBook 无外屏实际进入休眠与盒盖仍在外屏运行是不同状态；不能见到 lid closed 就一律撤场或拒绝认证。

## 一台相机对应一个注视目标

产品设置登记的是相机、目标显示器与注视校准配置的组合。Mac mini 的机箱位置不代表相机位置；
手机在附近也不代表用户正在看这个屏幕。左右屏幕、偏置相机、坐站距离需分别校准。
登记/换组合属于受强认证保护的设置操作，不能插上一台名叫 Studio Display 的设备便自动获得身份信任。

身份模板可在许可明确的同一模型下复用，但每种相机的曝光、镜像、裁切、分辨率和防伪阈值需单独评估。
人物居中、人物跟踪、肖像背景、自动取景与变焦会改变头眼几何；不能拿图像中心冒充屏幕注视目标。
变化期间重建映射并返回未知，不接旧动作进度，也不强制修改用户全局视频效果。

已将 [LivenessBinding](../tools/liveness-lab/LivenessChallenge.swift) 增加必填 displayTargetReference：
它由适配器表示显示器身份 + 注视校准/几何配置版本。身份、动作、相机、屏幕目标与会话绑定。
切屏、拔插、校准变化、相机变化时旧 evidence 失效；未知目标不能启动。
131 条合成检查已通过，包含换显示目标后撤销已完成证据与空目标拒绝。
这不是已实现的注视模型或显示热插拔适配器；不能由调用方填字符串就冒充已校准。

## 原生候选发现与本机证据

[相机探针](../tools/presence-probe/README.md) 使用 AVFoundation DiscoverySession 的
builtInWideAngleCamera 和 external 两种类型。本机实际枚举到 MacBook Air、Studio Display 与连续互通手机相机。
Studio Display 当前报告 builtInWideAngleCamera，但 transportType 为 USB；所以只筛 bltn 会错误排除它。
此前筛选现已改成：默认观察只自动选唯一内建传输相机，外接/其它来源须通过 --camera-index=N 明确选择。
默认能力模式不开相机。序号仅用于诊断，不稳定、不保存为生产信任标识，重新插拔后必须重新核对。

```
bash tools/presence-probe/run.sh --capabilities
bash tools/presence-probe/run.sh --observe --camera-index=1
```

当前列表的 1 是 Studio Display，不保证下一次还是 1。相机权限仍为 notDetermined，
显式 Studio Display 观察请求在权限检查退出 1；未请求权限、未采集画面。
连续互通手机仅列为候选；其相机画面与同一手机持有不能算两个独立持有因素。
公开设备信息不是硬件采集证明，外接认证仍需针对输入注入/重放进行攻击评估。

## 每块屏的翻盖与安全画面

动画场景与身份交易分开：系统会话只解锁一次，多块屏各自维护进度、速度和安全生成素材。
盒盖模式在外屏做虚拟翻盖或短淡入，不伪装成测到了物理掀盖角度。
Mac mini 的运动/角度缺失不降低身份认证，也不算异常。

锁屏前先撤销所有屏幕的桌面采集/缓存使用，再呈现安全素材；热插拔新屏从锁定的安全状态开始。
系统锁状态未知时任何屏幕都不能恢复桌面。确认系统真正解锁后，取得各自的新桌面帧再接续动画。
锁屏层不能挡住任一屏上的系统密码/Touch ID 提示，认证取消后保留系统恢复入口。

真机验收必须覆盖开盖到盒盖切换、外屏唤醒、两块外屏、主屏变更、不同 DPI、相机拔插、
显示器供电断开、人物居中变化、系统认证提示位置与睡眠中断；当前未完成这些场景的真实解锁验证。
