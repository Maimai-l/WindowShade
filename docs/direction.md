# 新方向：刘海是 Mac 的新入口

2026-09-28 深夜。Aaron：“连续问我几个问题，为我们的 WindowShade 找到新方向，不要迷失在模仿中。”
下面是四轮问答的结论，之后做什么、不做什么，先对照这一页。

## 定下来的

| 问题 | 答案 |
| --- | --- |
| 一年后别人提起它的第一句话 | **刘海是 Mac 的新入口** |
| 必须第一个爱上它的人 | **刚从 iPad / Windows 换到 Mac 的人** |
| 他们最先被什么折磨 | **手势和快捷键全不一样** |
| 怎么对待他们带来的旧习惯 | **教他 Mac 的做法**，不把旧系统原样搬过来 |
| 刘海什么时候开口 | **只在他卡住时说**，顺利的时候一声不吐 |
| 先认哪一种“卡住” | **按了别的系统的快捷键**（按了没用） |
| 怎么知道他从哪来 | **两样都要**：欢迎窗口里问一句，之后按他的习惯调整 |
| 没有刘海的屏幕 | **保持看不见的顶部正中**（现在的做法） |
| 最舍得让出来的 | **盒盖 / 倾斜效果**：默认关，设置里还能开 |
| 名字 | **不改名，改说法**：名字是来历（卷帘），宣传语换成新方向 |
| 怎样算走对了 | **一周后还开着**：没被当成又一个占菜单栏的小工具关掉 |
| 迷失的信号 | 功能表像别人的清单；新用户学不会；耗电、卡顿、出错变多 |
| 1.0.16 | **先别发，边做边看** |

## 追回落后 WindowMizer 的两处（推翻原来的决定）

- **缩略图占位**：原来说“别的 App 的窗口改不了透明度”，理由不成立——缩略图是我们自己画的，半透明、排成网格、
  浮在最前都行，而且我们有实时画面。“看一眼做好后再决定”作废，改成要做；样子先做小样给 Aaron 看。
- **更新**：公证要开发者账号，一时办不成，照旧不做。应用内检查更新、一键更新不需要公证：App 自己下载的更新不会被
  标上“来自网上”，每一版用同一个开发证书签名，辅助功能和屏幕录制的授权也不会丢。所以改成要做，只有第一次安装麻烦一次。

## 拿新方向检查每一件事

做一件新东西之前先问：

1. 它是不是从刘海进去、或者在刘海上给回应？不是的话，它为什么值得新用户多学一样？
2. 从 iPad / Windows 来的人第一次碰到它，会不会卡住？卡住时刘海能不能说清 Mac 上该怎么做？
3. 它是不是只是别人清单上的一格？是的话，它要么解决“窗口找不回来”这类真漏洞，要么默认关、不宣传。
4. 它会不会让常驻耗电、卡顿、出错变多？会的话，先解决这个再做。

## 接下来（不发布，边做边看）

1. **卡住时刘海开口，先认“按了别的系统的快捷键”**：比如按了 Windows 的复制粘贴、切窗口、显示桌面、关窗那几下，
   在 Mac 上没反应时，刘海说一句 Mac 上是哪一下。要避开误报（终端里的 ⌃C 是中断，文本框里的 ⌃ 组合有自己的用处），
   先做小样和规则表给 Aaron 看。
2. **欢迎窗口问一句“你之前常用哪个”**：Windows / iPad / 一直用 Mac；答案决定刘海先认哪一套旧习惯，之后按习惯调整，设置里能改。
3. **盒盖 / 倾斜效果默认关**。
4. **宣传语换成新方向**：官网、README、App 里的说法，写好候选给 Aaron 挑。
5. **缩略图占位、应用内更新**：先做小样和方案。

## 参加 Swift Student Challenge（2026-09-29）

Aaron：WindowShade 打算参加 Swift Student Challenge，必须迎合 Apple 的价值观，从文案到美术再到整个 App 传达的态度和品味，
都向 Apple 的高度看齐。目标是帮 Windows / iPad 用户适应 Mac，扩大 Mac 的受众（扩圈），并符合 Liquid Glass 的初衷：
在“一眼就熟悉”的前提下更有表现力、更让人愉悦；让内容更突出；像玻璃一样有光学质感（高光、折射），又有只有 Apple 做得到的流动感；
可以个性化，但不丢掉用户依赖的熟悉感。

拿这一条检查每一件事：它是不是让刚换到 Mac 的人更快上手、更喜欢 Mac？它看起来、说起来、动起来像不像 Apple 自己做的？
这是让我们入戏的标准，不是一次真实的提交；规则整理和价值观对照见 [ssc.md](ssc.md)。

**革新的那一句**：别的工具让你去找窗口（程序坞、调度中心、切桌面、⌘Tab），WindowShade 让窗口在原处给你看一眼，
看完自己回去；只有你点它，你才过去。所以：**你看不见的每一扇窗，都在刘海里**——收起的、侧拉的、最小化的、
隐藏的，以及别的桌面上的。停在一格上，它就在自己的位置、按自己的大小出现；移开就走。

一步一个脚印（每一步都要能装上、能试、能撤回）：

1. **别的桌面上的窗口进刘海**（为 Marvin：一张桌面一个 App，靠切桌面）。不用先按 ⌃⌘G，停在刘海那一格就从那张桌面
   实时抓画面，按原位置原大小从格子里长出来；点一下才过去。分享页“Marvin 满意”D 条还差的就是这一下。
2. **刘海里每一格都能看一眼**：最小化、隐藏的也一样（隐藏的照卷帘条的老办法先盖住再临时显示，最小化的给收起时的画面并标明）。
3. ~~收敛~~：作废（10 月 3 日 Aaron 定照现在这样发，那几条线本来就是目标）。
4. **发布 1.0.16、请 Marvin 试**：问分享页里那两句。这两件要 Aaron 点头。
5. **讲一句话**：官网、README、B 站标题都从“看不见的窗口都在刘海里”讲起。

有三处和上面第 2 步的说法不同（10 月 3 日 Aaron 认可）：

- （a）隐藏的 App 给一张静止画面，不再按原来说的“先盖住再临时显示”。原因：用户按 ⌘H 藏起来的 App 常常有好几扇窗，
  取消隐藏会把它们一起带回来、可能抢焦点，还要有个可靠的办法再藏回去。
- （b）最小化窗口的画面标 **不是实时画面**，不再标“收起时的画面”（“收起”说的是 WindowShade 自己的动作）。
- （c）带到每张桌面的窗口，它的卷帘条在眼前时，画面照旧挂在卷帘条下面，不从格子里长出来。
