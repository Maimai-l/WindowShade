# 竞品调研：Wins

更新于 2026-09-27。完整的竞品对比在分享页[《为什么不用最小化》](https://claude.ai/artifact/RkLPV8yCJNhuYYoH636TrT)，这里只放 Wins 的调研底稿和对我们的具体用处，结论已并入那一页。Wins 的功能、价格、用户数来自它官网的自述，没有下载试用。我们的现状以 `claude/three-finger-flick` 工作树为准（含尚未提交的侧拉、刘海、启动台），不以本地 main 为准：本地 main 落后于 origin/main，没有 9 月 26 日重新发布的三分屏、甩一下和四角。

## 结论

Wins 和我们的交集有两处：Dock 悬停看窗口，以及从刘海长出来的落点小岛。后者是这次调研最重要的发现：Wins 3.4（2026-06-29）把分屏的落点做成和刘海融为一体的小岛，我们的刘海也有“拖着标题栏靠近刘海，垂下一块落点小岛”。外形一样，用途不同：它落下去是分屏，我们落下去是收进刘海。[刘海说明](notch.md)里的调研只提到 MacNotch、Notchy 两家拖到刘海附近贴成半屏的工具，漏了 Wins，而 Wins 是其中用户最多的一家，需要补上。

Wins 其余的核心（替换 ⌘Tab、改造调度中心、再点 Dock 图标就最小化、锁定 Dock）都在接管系统入口，和“收起窗口，留下位置”不在一条路上，不跟。

## Wins 是什么

国内团队做的付费 Mac 窗口工具，当前 3.6（2026-09-15，适配 macOS 27），支持 macOS 12 以上，Apple 芯片与 Intel 都能用。官网自述 13,266 名用户，2024-08 的更新日志写过月活破 5 千、日活过千。一次买断：个人 ¥139（1 台、1 年更新）、Pro ¥279（3 台）、X ¥356（5 台），1 天试用。没有菜单栏图标，也不占 Dock，设置面板装在系统设置里。

| 功能 | 做什么 |
| --- | --- |
| 悬浮分屏岛（3.4） | 拖窗口时刘海处长出布局小岛，拖上去即分屏；3.3 起支持竖放的外接屏 |
| Cmd-Tab Plus（3.0） | 与系统 ⌘Tab 并用，列出每个 App 的窗口，数字 1/2/3 选窗口 |
| Dock 窗口预览 | 悬停 Dock 图标列出窗口，可在预览里关窗口 |
| 调度中心 Pro（2.5） | 在调度中心里用 ⌘W/⌘Q 关窗口、退出 App |
| Dock 窗口反转（2.6） | 再点一次前台 App 的 Dock 图标就最小化 |
| 隐藏其他 / 最小化全部 | 抖动窗口或按快捷键；“最小化全部”再按一次全部召回，前后顺序不乱（3.4） |
| Dock 锁定屏幕（3.5） | 把 Dock 固定在某块显示器 |

## 对我们有用的地方

**1. 刘海落点小岛的验收用例。** Wins 在分屏岛上修过的问题，我们的落点小岛大概率也会遇到：调整窗口大小的拖动误触发小岛（3.3 修过，3.5.1 又修一次）、竖放的外接屏（3.3）、macOS 27 上拖动时反复读取窗口状态导致卡顿（3.5.1）。这些该补进刘海的实机验收，对应登记里的 R23–R25 和 R33。

**2. 排布前先看窗口能不能改大小。** Wins 3.5 让分屏岛和边缘吸附忽略不能调整大小的窗口。工作树里的三分屏梯子、甩一下、四角和键盘排布都还没有提前判断，`isAXSizeSettable`（`prototype/Window/AXWindow.swift:83`）只用在卷帘条自身。固定大小的窗口现在具体怎么失败，待实测（计算器、系统设置可复现）。这和登记 R46 的“做不了时浮窗说一句，不假装做了”是同一条原则。Rectangle 2.0.1（2026-09-26）的做法可以参照：App 不肯缩到要的大小时，浮窗说“达到最小尺寸”。

**3. “再按一次恢复”的样子。** Wins 的“最小化全部”再按一次，全部召回并恢复前后顺序。登记 R07 的“暂时取消全部置顶”要的正是这个：一次取消、再按恢复，而且回来时前后顺序不乱。这是可参照的行为，不是现成代码；R07 仍要按现有的置顶流、租约和 Space 逻辑重新设计。

**4. Dock 预览的验收用例。** 快速在图标之间移动时面板消失（3.6）、Dock 自动隐藏时挡住 Dock（2.6.1）、右键或长按 Dock 时面板盖住菜单（2.6.2）、窗口太多超出屏幕（2.6.2）、唤醒后缩略图带红绿灯（3.1、3.4 两次）、台前调度下缩略图变形（2.6）、已关闭的窗口还留在列表里（多次）。我们已经处理了 Dock 四个方向和唤醒通知，但没按这些场景在真机上跑过；可补进 [窗口浏览视觉验收](window-browser-visual-qa.md)，对应合同 E–I 与 R42。

**5. 设置里的功能演示。** Wins 3.0 在设置面板里给每个功能放了演示。可以并入设置设计稿阶段 2–4（R35）和手势教学（R14），属于提议，还没采纳。Wins 3.1.1 踩过的坑：演示视频带音轨，播放时抢走了 AirPods，所以要用无音轨素材或 Core Animation。

## 已有或已定，不必从 Wins 学

- 隐藏其他窗口：我们有“专注当前 App”，而且收成卷帘条留在原处。
- 拖到屏幕边缘分屏：已定交给系统（R05）。
- 公证与自动更新：Aaron 已定暂不做（2026-09-25）。
- 把设置装进系统设置：设置走原生独立窗口（R35、R36），菜单栏是找回窗口的入口，不能去掉。
- 官网上的资源占用数字：Wins 的两处数字对不上（30 MB 与 70 MB）。我们要写，必须用当前版本重新测，M1 上没测过就不写（R30）。
- 营销方式：官网的“刚刚有人购买”弹窗、倒计时、“仅限前 100 名”和文案规则冲突。
