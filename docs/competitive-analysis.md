# 竞品调研：Wins

更新于 2026-09-27。这里放 Wins 的调研底稿和对我们的具体用处。Wins 的功能、价格、用户数来自它官网的自述，没有下载试用。

## 结论

Wins 和我们的交集是 Dock 悬停看窗口。

Wins 其余的核心里，替换 ⌘Tab、再点 Dock 图标就最小化都在接管系统入口，和“收起窗口，留下位置”不在一条路上，不跟。锁定 Dock、调度中心里用 ⌘W 关窗口，我们也有（Dock 留在一块屏上、调度中心里的 ⌘W / ⌘Q）。

## Wins 是什么

国内团队做的付费 Mac 窗口工具，当前 3.6（2026-09-15，适配 macOS 27），支持 macOS 12 以上，Apple 芯片与 Intel 都能用。官网自述 13,266 名用户，2024-08 的更新日志写过月活破 5 千、日活过千。一次买断：个人 ¥139（1 台、1 年更新）、Pro ¥279（3 台）、X ¥356（5 台），1 天试用。没有菜单栏图标，也不占 Dock，设置面板装在系统设置里。

| 功能 | 做什么 |
| --- | --- |
| 悬浮分屏岛（3.4） | 拖窗口时刘海处长出布局小岛，拖上去即分屏；3.3 起支持竖放的外接屏 |
| Cmd-Tab Plus（3.0） | 与系统 ⌘Tab 并用，列出每个 App 的窗口，数字 1/2/3 选窗口 |
| Dock 窗口预览 | 悬停 Dock 图标列出窗口，可在预览里关窗口 |
| 调度中心 Pro（2.5） | 在调度中心里用 ⌘W/⌘Q 关窗口、退出 App |
| Dock 窗口反转（2.6） | 再点一次前台 App 的 Dock 图标就最小化 |
| 隐藏其他 / 最小化全部 | 抖动窗口或按快捷键；“最小化全部”再按一次全部召回，前后顺序不乱（3.4） |
| Dock 锁定屏幕（3.5） | 把 Dock 固定在某块显示器 |

## 对我们有用的地方

**1. 排布前先看窗口能不能改大小。** Wins 3.5 让分屏岛和边缘吸附忽略不能调整大小的窗口。我们排的时候保持原尺寸，放在目标区域正中。Rectangle 2.0.1（2026-09-26）的做法可以参照：App 不肯缩到要的大小时，浮窗说“达到最小尺寸”。

**2. “再按一次恢复”的样子。** Wins 的“最小化全部”再按一次，全部召回并恢复前后顺序。我们的“暂时取消全部置顶”也是这样：一下让开全部置顶，再按一下按原来的前后顺序放回。

**3. Dock 预览的验收用例。** 快速在图标之间移动时面板消失（3.6）、Dock 自动隐藏时挡住 Dock（2.6.1）、右键或长按 Dock 时面板盖住菜单（2.6.2）、窗口太多超出屏幕（2.6.2）、唤醒后缩略图带红绿灯（3.1、3.4 两次）、台前调度下缩略图变形（2.6）、已关闭的窗口还留在列表里（多次）。我们已经处理了 Dock 四个方向和唤醒通知，但没按这些场景在真机上跑过；可补进窗口浏览的实机验收。

**4. 设置里的功能演示。** Wins 3.0 在设置面板里给每个功能放了演示。属于提议，还没采纳。Wins 3.1.1 踩过的坑：演示视频带音轨，播放时抢走了 AirPods，所以要用无音轨素材或 Core Animation。

## 已有或已定，不必从 Wins 学

- 隐藏其他窗口：我们有“专注当前 App”，而且收成卷帘条留在原处。
- 拖到屏幕边缘分屏：已定交给系统。
- 公证：Aaron 已定暂不做（2026-09-25）。
- 把设置装进系统设置：设置走原生独立窗口，菜单栏是找回窗口的入口，不能去掉。
- 官网上的资源占用数字：Wins 的两处数字对不上（30 MB 与 70 MB）。我们要写，必须用当前版本重新测，M1 上没测过就不写。
- 营销方式：官网的“刚刚有人购买”弹窗、倒计时、“仅限前 100 名”和文案规则冲突。
