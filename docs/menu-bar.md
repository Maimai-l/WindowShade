# 菜单栏菜单：从 24 项收到个位数

2026-10-03。Aaron：“菜单栏的菜单也是，不可无节制扩张。”

收之前的菜单有 24 项，问题有三个：

- 开发用的项混在里面（屏幕开合角度等）；
- 开关放在了菜单里（双击标题栏收起窗口等）；
- 对当前窗口的动作排成一长串，常用的和少用的一样显眼。

## 规则

1. **菜单只放两种东西**：对当前窗口做的事，以及打开设置、退出 WindowShade 的入口。开关进设置，开发用的进开发菜单。
2. **常用的平铺，少用的收进一个子菜单。**一级菜单不超过 12 项（不算“已收起的窗口”这一段）。
3. **每项都带 SF Symbol**，名字照 copy-guide；快捷键照设置里录的。
4. **新功能不默认进菜单。**要加一项，得先拿掉一项，或者证明它比现有某一项更常用。

## 现在

```text
当前窗口                                               （标题行，不可点）
  rectangle.compress.vertical  收起窗口
  rectangle.grid.1x2           整理卷帘条       （选“缩略图”时是整理缩略图）
────────
  （收着窗口时才出现）已收起的窗口 … · 全部展开
────────
  gearshape                    设置…              ⌘,
  power                        退出 WindowShade   ⌘Q
```

每项的快捷键照设置里录的显示；新安装时不设快捷键，从 1.0.15 及更早版本升级的保留原快捷键（收起窗口 ⌃⌘C、整理卷帘条 ⌃⌘0）。
按住 ⌥ 时，“设置…”换成“关于 WindowShade”，“退出”上方多出“检查更新…”，这是 macOS 菜单的惯例。

## 移出菜单的项

| 原来的项 | 现在的入口 |
| --- | --- |
| 屏幕开合角度 | 合盖效果已经删除，这一项也随之删除 |
| 双击标题栏收起窗口 | 设置 → 卷帘（已有这一行） |
| 欢迎使用 WindowShade… | 首次打开和缺权限时自动出现；设置 → 高级 里随时能再打开 |
| 关于、检查更新… | 按住 ⌥ 出现；检查更新在设置 → 权限与启动里也有 |
| “收起当前窗口”…… | 标题行已经说了是对当前窗口，名字去掉“当前窗口”，短一半 |

## 验收

- 发布版一级菜单常驻项 ≤ 12；开发用的项在发布版里看不到。
- 每个功能仍然至少有一个入口：快捷键、设置或菜单，不能有功能因为挪出菜单而找不到。
- 读屏念出来的名字和看到的一样；每项有符号和快捷键。
- 现有和菜单有关的测试（包括 `StandardMenu` 的“已收起的窗口”分段）改成新结构后照样通过。
