## 整体完成标准

必须跑通：开盖 → 真锁屏上的安全动画 → 选定摄像头 → 本人匹配 + 注视 + 活体 → 当次设备因素/抽查 →
系统真实解锁确认 → 新鲜桌面交接。取消、重放、权限缺失、设备/显示器切换、再合盖、睡眠必须撤销旧结果。
有效系统密码/Touch ID 恢复始终可用。风险学习先观察、不自行锁人；真实误提示和攻击测试决定启用。

实时活动与手势逐项用真实来源和设备验收，不用模型测试、display-link 回调或功能文案代替。
“先求有再求好”允许实验功能明确开放，不允许身份、防伪、系统解锁和防盗能力拿占位实现充数。

## 当前实施顺序

锁屏与纹理/采集生命周期 → 相机动作与注视校准 → 本人模板及防伪 → 当次 Watch/iPhone 交易 →
系统解锁后端 → 离位/盗抢 → 原生环境与行为影子学习 → 真机误报与动画/能耗验收。
实时活动和手势继续并行补验收，不因此删掉安全目标。
